## 第一部分 · 1. 一句话结论

主干不需要换。现有设计由四部分组成：对 q 线性的延拓、精确刚体分离、精确端口值、变分读出 Ŝ = ÊᵀKÊ。有了这四部分，晶格解就是学习试探空间里的 Ritz–Galerkin 解，同时还免费附带一个严格、不需要标签的误差下界。现在的瓶颈不在容量，而在三件事：

- step-2 泛化为什么失败，还没有用合适的证据测过；
- 训练用的 q 分布、以及最坏方向 μ 所在的尾部，与晶格实际用到的方向不匹配；
- 下游没有任何可信度信号。

建议的顺序是：先拿 v1 的检查点做一轮零成本诊断，再按判据做只动几何路径的低风险加固，同时加入晶格情境下的采样。虚拟边缘续延头、45 节点 GP 面模板、粗层改造，都等诊断结果满足条件再做。

## 第一部分 · 2. 瓶颈在哪里（按证据）

### 2.1 step-2 泛化：问题最关键，证据却最弱

- **现有证据不够用。** 目前的失败证据几乎全来自单几何网络的零样本测试（力类 107–2236%，r1 达 1e3 倍）。只见过一个几何的网络过拟合是意料之中的，这些数字分不清是架构不稳定，还是网络根本没学过这类几何。
- **有两种机制，代码里都找得到依据。**
  - **软方向放大。** 力类方向的 Rayleigh 商中位数是 1.8e-7，宏观类约 1e-4。同样的相对振幅误差，在软方向上的能量代价要高 1e2–1e3 倍，几个百分点的振幅误差就能产生 100–400% 的能量误差。任何架构都会有这个问题，只能靠数据覆盖和尾部训练压下去。
  - **增益失控或垃圾值。** FULL0020→dev_0002 的宏观类误差 1745%、随机场 869%，约为零参数调和延拓的 40 倍，合理的插值不会差到这种程度。代码里对应的因素有：
    - 槽位系数是 0.2·MLP，没有界；
    - 延拓权重是 softplus，没有上界；
    - 大约 40 个受几何调制的线性级串联；
    - 输入特征 ld = log(d3/本几何中位数)；weak 定义为本几何中位数的 1%，而且这个 weak 同时决定 fringe 层的作用范围（models.py:119、336–337；prep_data.py:123）。

    结果是特征的含义随厚度分布漂移。
- **首次进池最坏比 106→4.7 不能当作架构尾部的证据。** 它由 k=8、4 次随机起点的幂迭代算出，没有收敛，只是下界；而且正好落在前 3k 步学习率热身期，网络又是从单几何 r2 出发的。它能说明跨几何的结构学得动，仅此而已。
- **训练器本身会混淆测量。**
  - 池里 3 个几何、每 300 步换入一个，60k 步只走 1.35 遍，每个几何每次驻留约 300 步，学习率最高 1e-3。
  - 探针是 order[:12]（train2.py:243），在 10k–40k 之间测到的主要是遗忘，而不是泛化。
  - validate() 只报能量的类均值，没有灵敏度、p90、μ，也没有分族数字。
  - best.pt 按"最大类均值能量"选，不一定是过门最好的模型。

### 2.2 step-1 残余精度：尾部加分布偏移

- **能量误差是场误差的平方。** 库误差 1.8–2.4% 对应能量范数下约 13–15% 的场误差；μ = 1.31–1.48 意味着最坏方向的场误差达 56–69%。门之所以能过，靠的是 Galerkin 配对：延拓误差 5–10% 和界面误差 3–9% 符号相反，在结构上互相抵消到 2–3%。

  **推论：** 网络自己的场必须和它自己的变分反力成对使用。任何局部后修正、换一个反力、或所谓"精确恢复"，都会退回到单侧误差。
- **界面误差由 μ 控制，而 μ 目前只报告、不训练。**
  - 记 Δ = Ŝ−S ⪰ 0，ΔR = 0。单个学习胞造成的晶格端口误差满足 ‖δU‖/‖q‖_S ≤ √((1−1/μ_eff)·ε_q)，其中 μ₋F ≤ μ_eff ≤ μ（μ₋F 指共享面固定时的值）。
  - 代入 μ = 1.31–1.48、ε_q = 2–2.4%，界为 7–9%，实测 3.3–9.3%。nbr_z 载荷的 ε_q ≈ 1%，界约 5.7%，实测 4.8%。
  - 训练损失是 mean log ê。它对误差 2% 的方向和误差 100 倍的方向给出的梯度是同一量级，并不偏向尾部。
  - step-2 的对抗搜索只有 8 个向量、4 次迭代，每次进池就覆盖，远弱于 step-1 的做法（每 500 步热启动、缓冲 256 个向量）。
- **q 分布有偏移。** 把精确的晶格端口数据喂给网络，单看延拓部分的灵敏度误差是 5.3–9.9%；而在样本库上只有 0.6–1.5%。代码确认了原因：
  - force/face/support 三类都是把端口节点上采样的光滑场直接当节点力，虚拟边缘节点也受力（prep_data.to_ports 只做了 reshape）；
  - 弹簧刚度取 α × 面平均对角（prep_geo.py:62–65），把虚拟边缘夹得比它自身刚度硬 1–100 倍；
  - 而验收门用的是按面力一致的载荷加上与母胞粘接；
  - 设计文档 6.3 要求的"三分之一一致载荷"没有实现，"被拖着走"的状态也从未采样。

  另外，灵敏度里有一部分一阶误差不受 Galerkin 保护（dK/dτ 中不与 K 成比例的部分）。所以，拿到晶格情境下的灵敏度标签，比加大样本库上灵敏度损失的权重更关键。
- **虚拟边缘。**
  - 在 r1 v0 上，36% 的误差能量落在 GP 项，45% 的体误差落在含 weak 节点的单元。
  - GP 面超边只取了 0–4 层节点中的 1–3 层（models.py `_face_setup`），而 Q2 的两个跳跃泛函需要第 0 层和第 4 层。
  - 不过这些份额是在 v0 上测的，没有按单元数归一。切割胞里含 weak 节点的单元可能本来就占一半左右。
  - 单元层和面层交替堆叠，可以组合出 5 层泛函，所以限制在于每层的表达力，而不是"看不见"。
  - MGNO2 上的份额还没有测。
- **两点需要注意：**
  - nbr_z 的"界面 4.8% / 延拓 1.0%"是在 d2 之前的 MGNO2 上测的（那时总误差 4.4%），d2（3.10%）还没有做拆分；
  - 单个载荷有 ±0.2–0.3 个百分点的波动完全可能。

  fp32 不是瓶颈：两条 fp32 路径的能量差是 5–7e-6，约为 ε 的 0.03%。

### 2.3 下游使用

- **坏胞会静默失败。** 不管权重是什么，Ŝ ⪰ S 都成立，所以坏胞只会让晶格偏刚。PCG 照常收敛，灵敏度却被污染，目前也没有任何报警。
  - 读出过程其实已经算出了 r = Kû。因为端口精确，而精确延拓是 K-调和的，所以 r_I = K_II·e_I，并且 Δ(q) = qᵀ(Ŝ−S)q = r_Iᵀ K_II⁻¹ r_I。
  - 对任意内部向量 w，有 (wᵀr_I)² / (wᵀK_II w) ≤ Δ(q)。这是一个严格的下界，不需要求解，目前还没有用上。
- **当前的门低估了部署时的误差。**
  - 现在只有被测胞是学习的，它的误差会按能量占比打折：测试载荷打 0.13–0.41 折，邻居载荷打 0.0013–0.011 折。
  - C−Ĉ 在各个学习胞上符号相同、直接相加，所以全部用学习胞的晶格会更苛刻。部署透镜估计 2 胞全学习时柔度误差约 2–3.5%，这个数还没测。
- **step 3 才需要处理的问题。**
  - weak 用硬阈值，导致 Ĉ(τ) 在固定拓扑内跳变，没有一致的梯度。
  - 每个 FULL 胞约需 1.2 GB 网络记录加 2.4 GB 的 K（估计）。
  - 晶格求解目前只有 2 胞的稠密 Cholesky。

## 第一部分 · 3. 推荐改动

**约束核对。**
- 下面所有主线项都是完全学习的：精确 K 只出现在读出、损失和监控里。
- 证书里的 Krylov 迭代只用于监控，从不进入场。
- SGNO 类方法和测试时自适应只能作为单独标注的退路。

**实现优先级。** 前景相当时，优先选只改几何路径的项（B1–B3），因为它们复用已经验证过的 q 路径核。改 q 路径核（B5）要同时改三处：models 稠密路径、sparse_layers 的手写反向、fastnet 的显式伴随，然后重跑 t_fast 验证。

- 可能把 v1 挤到显存溢出；

### B. 核心架构改动

各项都是完全学习的。

**B1 有界几何系数（G1a；把 P5 的延拓幅度上限、P2 的 tanh 部分、L7 的上限合并进来）——建议作为 v2 的默认项**
- **模块：** slot_head / fslot_head / slot_head_x / restrict_head，以及 MGCache 的输入。
- **改法：**
  - 槽位系数改成 a = A·tanh(a_raw/A)。A 取训练几何上 |系数| 的 p99.9 的 2–3 倍，在 v1 最终检查点上标定，存为固定缓冲。
  - 延拓权重改成 w = w_max·tanh(softplus(r)/w_max) + 1e-3。
  - 矩比 M/vol 截断到 [−1,1]：在中心化的局部坐标下，合法值本来就在这个范围内。ld 也做截断。
  - 每个几何记录系数的饱和比例，作为免费的分布外（OOD）分数。
- **针对的问题：** O(1) 量级的增益失控，例如宏观类 1745%。
- **预期（估计）：** 去掉极端尾部，均值基本不降。p99.9 处的值最多变约 8%，中位数几乎不变。每层的界是 1 + 27HA_aA_b‖W‖，这个界太松，挡不住 24 层的复合放大。它真正的作用是保证分布外特征最多饱和到训练范围，而不是无限放大。
- **风险和成本：** 低。步时增加不到 1%。热启动近似保持原函数，需要 LR 3e-4 的短微调。只在几何路径加 LayerNorm 的版本（G1b）留给从头训练的 run。
- **验证：** 从 v1 最终检查点接着训 1 万步，与共享对照比较。通过条件：
  - val 各几何力类均值的最大值 ≤ 对照的 0.6 倍；
  - 首次进池 Ritz 值的中位数 ≤ 对照的 0.7 倍；
  - 各类均值变化在 ±5% 以内。

**B2 几何一致的输入特征（G3，加上 D4 的特征部分）——由 A1/A3 触发**
- **模块：** MGCache.nfeat，MGNO2 的 fringe 掩码。
- **改法：**
  - 把 ld 换成 log(d3/d_ref(t))。d_ref 是某类 Q2 节点（顶点、棱、面、体心）在全实心时的解析值。所有几何共用 E、ν、h，所以 d_ref 是常数。
  - 新增软 weak 分数 s = σ((log₁₀(d3/d_ref)+2)/0.15)。
  - 新增到端口的图跳数，以及到裁切面和盒面的有符号距离（截断在 6 个单元）。
  - 分两步做：臂 1 只加新列，输入权重零初始化，旧掩码不动；臂 2 再把 fringe 层改到固定的超集掩码上，并按 s 平滑渐入。
  - **保留 sin/cos 坐标。** 所有胞都是同一个 Schwarz-P 单胞，绝对相位是真实的几何信息，在 O_h 下协变。
- **针对的问题：** 同厚度 FULL 之间迁移误差 8.5%，不同厚度之间 2236%；weak 阈值随中位数移动，导致 fringe 层的作用范围跳变。
- **预期（估计）：** val 误差或训练-留出差距下降 10–25%。附带让 Ĉ(τ) 在固定拓扑内连续，这是 step 3 需要的。
- **风险和成本：** 低到中。特征计算只要毫秒级；改掩码后需要 2–5k 步重新学习。

**B3 按刚度份额散射（P2 与 G7a 的最小版）——由 A4 触发**
- **模块：** 只改 β 值和散射归一化，q 路径核不动。
- **改法：** 散射改成 dX_i = Σ_e π_{e,i} Y_{e,i}，权重 π_{e,i} = ‖K_e[s,s]‖ / Σ_{e′∋i}‖K_{e′}[s,s]‖；GP 面用 γ‖G_f[s,s]‖。与旧的 1/deg 用可学的 λ 混合，λ 初始化为 0。
- **依据：** 精确解的边缘值满足 (Ku)_W = 0，本身就是强邻居节点的刚度加权组合。现在网络得靠 MLP 从 ld/5 这一个特征里合成 2–4 个数量级的刚度差。
- **去掉的部分：** 零和投影和 l1-Jacobi 守卫。"每层非扩张"并不成立（κ 不对称，W 无界），这两项降低表达力，又没有证据支持。

**B4 带门控的虚拟边缘续延头（L3；合并 P3、G7b）——由 A8 判定做不做**
- **模块：** 输出级，放在 W_out 之后、端口覆盖之前。每个几何在 MGCache 里多一个几何算子 C。
- **改法：** u ← u + diag(g)·M_W(Cu − u)。
  - C 只用网格、软 weak 分数和 vf 构造，不含 K。两种取法：AgFEM 根单元多项式在该点的值，或邻域非 weak 节点上的最小二乘仿射。两者都能精确再现刚体运动和均匀应变。
  - 门控 g_w = σ(head) 初始化接近 0；四周全是空单元的节点初始化约 0.9。
- **保持不变的性质：** 对 q 线性、端口精确、刚体精确；Ŝ 仍然对称半正定且 ⪰ S。
- **针对的问题：** GP 加 weak 区的误差份额；均布节点力压力测试 5.3–8.5%；零样本时边缘区的多余能量。
- **预期（提案估计，以 A8 通过为前提）：**
  - 边缘误差份额约减半；
  - 力类和支撑类库误差从约 2.0% 降到 1.3–1.6%；
  - 在新几何上，边缘能量被"强节点误差 × 延拓常数（2–8）"控制住。
- **风险：**
  - γ = 1e-4 时，精确的边缘场并不完全是延拓，因为 weak 节点的形函数会伸进切割单元的材料里；
  - 薄壁处根单元稀缺（vf 0.1 时壁厚约 1.4h）。
- **成本：** 约 150 行代码，前向和伴随各多一次稀疏乘。
- **学习型 Φ（P3）的条件：** 只在 A8 中 (i)(ii) 不过、而 (iii) 通过时才用。

**B5 与 GP 一致的 45 节点面模板（P1）——由 A4 触发**
- **改法：**
  - 先只改 4 个 fringe 面层，模板取 5 层节点 × 3×3，旧的 27 槽权重零嵌入，热启动时保持原函数；
  - sparse_layers.pattern 和 fastnet._Hyper 从 27 槽泛化到 S 槽。
- **J 投影版的前提：** 必须先从 GP_TEMPLATES 的 F_axis 用 SVD 求行空间得到 J，不能假设它是 Kronecker 形式（DATA_INTERFACE 里标注那只是猜测）。
- **预期（提案估计）：** GP 份额减半，力类和面类库误差降 15–30%。这个前提在 MGNO2 上还没验证。
- **成本：** GP 面的数量约为单元数的 1.7 倍（FULL 为 21.9k 对 12.9k）。如果所有面层都改，步时会增加 30–45%，而且得先靠激活重算腾出显存。

**B6 O_h（48 元立方群）增广——需要你同意把它提前**
- **模块：** 训练器（Slot/Geo.field 包装），网络本身不动。
- **改法（G4 的数据侧视图）：**
  - 节点做置换，位移分量做带符号的置换，矩做带符号的置换，单元槽重排，GP 面的轴也跟着置换；
  - 能量和灵敏度仍在原坐标系里、用原来的 K 和 dM 计算，不需要新标签。
  - 每次进池时随机抽一个视图。
- **分歧处理：** L1 的参数视图每步都能换新视图，更彻底，但变换表约 300 行，更容易出错。先做 G4，并把它当作检验 L1 正确性的参照。如果旋转后的误差仍大于未旋转的 1.2 倍，再上 L1。每个几何每次 run 只见到少数几个视图问题不大，因为不变性是在 148 个几何之间共享着学的。
- **针对的问题：** 你定的范围是"其他朝向靠旋转增广"，这件事还没实现，所以每个旋转后的朝向目前都等于零样本。
- **预期（估计）：** 旋转后误差不超过未旋转的 1.2 倍；未旋转的 val 可能因正则化受益，这点不确定。
- **成本：** 约 1 天代码。单元测试要求 *_rot* 包上能量相对差 ≤1e-5。

**B7 暂缓：几何和方向感知的粗层超边，加几何 U-Net（G2）**
- **暂缓理由：** 现有证据没有把失败定位到粗层路径——Rayleigh 间隙对任何均匀的振幅误差都成立；而且代价是步时 +8–10%、显存 +1–2 GB。
- **触发条件：** 做完 B1、C4、B6 之后，力类和支撑类的 val 误差仍以光滑分量为主（占比 >0.5），且差距一直存在。届时先只做 33³ 粗超边一个臂，β 零初始化。

### C. 训练目标与采样配套

**C1 晶格情境下的 q 类（P2 与 L4 合并）——证据支持最充分的采样改动**
- **三个新类：**
  - (a) 一致面力 force_c / face_c：f_i = ∫_{Γ∩材料} t·N_i dA，t 为随机光滑面力，复用门的一致积分；虚拟边缘节点几乎不受力。
  - (b) 弹簧改成 k_i = α·diag(K)_ii，α 在 [0.3, 3] 上对数均匀取值。
  - (c) 粘接类：
    - 与本族 FULL 母胞在一个有材料的随机盒面上粘接，远端固定或挂弹簧；
    - 25% 的样本只在邻居上加载，用来覆盖"被拖着走"的状态；
    - 粘接构型必须与门**不相交**：邻居放在 +x、+y、±z（门用的是 −x、−y）。因为算子对 q 线性，覆盖了门的 q 子空间就等于直接在门上训练；
    - 一次两胞分解，再做 64–96 次回代，就能得到 q_t、精确能量、反力 S·q_t 和精确灵敏度。
- **能量项不需要精确的晶格解。** log ê 对尺度不变；由包络定理，网络在自己晶格解 q̂ 上的能量梯度就是 Ĉ 的梯度。精确解只是为了灵敏度标签。在线 DAgger 刷新等离线版证明有效后再做。
- **预期（估计）：**
  - 在晶格端口数据上，单看延拓部分的误差降 30–50%；
  - r2 y 构型的被测胞灵敏度从 3.10% 降到 ≤2.5%；
  - 压力测试可能退约 0.5 个百分点，保留 5% 的节点力类可以缓解。
- **做法：** 先只在 r2 上跑两个臂：臂 A = (a)+(b)，臂 B = (c)。通过后再对 168 个几何全量重新准备数据：约 3–4 GPU 小时，不能与训练同时跑，磁盘增加 30–50%。同一趟顺便存下 F = S·q（C3 要用）。

**C2 灵敏度损失改成 smooth-L1（P4）——最便宜的改动**
- **改法：** L_s = mean √(ρ² + δ²)，其中 ρ = ‖ŝ − s‖/‖s‖，δ = 0.003。现在的相对平方误差在收敛附近只占约 0.5% 的梯度，改后约 25%。
- **分歧处理：** 失败的那一项主要是界面误差，而样本库上的灵敏度损失只作用于延拓那一半。结论如下：
  - 把它作为 step-1 的第一个 A/B 来跑，因为只需改配置；
  - 用 diag_lat 拆分看它动的是哪一半误差；
  - 不指望它单独修好 nbr_z，最终与 C1 一起捆绑进入。
- **不做的部分：** CVaR 和八分区标签。

**C3 尾部：先加强对抗搜索并把 μ 纳入验证，Ritz 尾损失视 A6 结果再定（合并 obj-P3/P5 和 EA-P4）**
- **先做（不改损失）：**
  - 每个几何在主机上保留一个 16–32 向量的对抗缓冲，跨访问不丢弃；
  - 首次访问时用 Neumann 分解做幂迭代，以 force/face 向量作种子，k=16；
  - 之后改用不需要分解的"库张成 Ritz"刷新：取 Ĝ_R = U_Rᵀ K U_R 对 G_R = Q_Rᵀ F_R 的前 8 个广义特征向量；精确反力 F_R·c 已知，所以不需要分解；
  - 每次 EVAL 在 5 个固定的 val 几何上报告 μ 和 μ₋F，固定种子，迭代到收敛。
- **A6 证实后再做——批 Gram 上的 Ritz 尾损失：**
  - 损失为 L = mean log Ĝ_bb + w_T·τ·logΣexp(log λ_i/τ)，其中 λ_i ≥ 1 是 (Ĝ, G) 的 Ritz 值。
  - 其含义是 Σ(λ_i − 1)² = ‖G^{-½}(Ĝ − G)G^{-½}‖²_F，也就是反力残差 (Ŝ − S)q 在对偶范数下、投影到当前批张成的空间上——恰好是驱动界面误差的那个量。
  - 每步多一次 16×16 的特征分解；G 的特征值要加下限 1e-3·λ_max；w_T 取 {0.3, 1.0}。
- **预期（估计）：** μ_bank − 1 约减半，界面误差降约 30%。
- **风险：** fp32 噪声被放大；可能以均值为代价换尾部。

**C4 训练器 v2（合并 obj-P1、D3、obj-P5，以及 L6 的几何层部分）**
- **换入节奏：** 约每 100 步换入一个几何。每 25 步不可行：装载要 2–5 s，Neumann 分解约 10 s，而 25 步训练只有 5.7 s。
- **其他改动：**
  - 池 3 个几何，加 DOF 上限，主机异步预取；
  - 分解只在几何首次访问时做；
  - 每批按固定的类配比抽样，不再用多项式随机抽；
  - 权重 EMA，衰减 0.9997；
  - validate() 增加灵敏度的均值和 p90、分族数字、5 个固定几何上的 μ；
  - 探针改成固定的分层抽样，并记录每个几何距上次访问的步数；
  - 选模型改为综合看灵敏度、p90 和 μ。
- **按条件开启的项：**
  - 按难度采样（上限 3/N，最后 10% 的步数回到均匀）只在 max/median >3 时开；
  - 继续训练已收敛的模型，学习率一律 ≤3e-4；
  - 激活重算只在 B5 或 B7 需要显存时再做：步时 +10–25%，需要复核梯度。

**C5 几何倍增。** 如果训练器 v2 加上 B6 之后，留出几何与训练几何的误差比仍 >1.5，就用生成器补充"轻标签"几何：只需组装加一次 fp32 Neumann 分解，每个几何约 20–30 s，只训练能量损失。τ 抖动（G6）暂缓，因为在固定单元集上改 τ，得到的并不是任何族成员真正的 CutFEM K。

**C6 数据修复。** 有 5 个几何的 support 类约 89% 是 NaN，要用 fp64 重算。修复之前，在分类均值里对它们做标注或排除，因为它们每个只剩 58/8/8 个样本。

### D. 下游与可信度

- **D1 残差证书（D1 与 G5 合并）——现在就做，零风险。**
  - **零参数版：**
    - 取 w = D_II⁻¹ r_I，D_II 是 NETDATA 里已有的 3×3 对角块；
    - 或者在 m=8–16 维的块 Jacobi-Krylov 子空间上算 bᵀG⁻¹b。
  - **能得到什么：**
    - 对每个查询，μ(q) ≥ 1/(1 − ε_lb)；
    - 在晶格层面，Σ_c Δ_lb,c(q̂_c) ≤ C − Ĉ，也就是柔度误差的一个严格下界；
    - 每个胞每次查询只需几毫秒。
  - **局限：** 对局部、粗糙的误差（比如边缘区）很准，对光滑的软模态误差偏松。没有便宜的严格上界，因为 K_II 的最小特征值极小。
  - **学习型证书头：** 只在 A5 显示力类和支撑类的下界效率低于 0.2 时才做。
  - **报警后的处理策略：** 被标记的胞整体替换为单独标注的退路，绝不在固定端口值下做局部修正。这是 Galerkin 配对的直接推论。
- **D2 全学习晶格门作为附加指标。** A7 的结果决定 step-2 的精度目标，例如每个胞在晶格方向上是否要做到 ≲1.5%。门本身怎么定义，由你决定。
- **D3 视图平均与集成。** 凸性只保证它不差于成员均值，不保证不差于最好的成员，而且灵敏度不在保证范围内。组平均放在 B6 之后做；r2 检查点的集成只作诊断用。
- **D4 留到 step 3：**
  - 连续特征，加上一致梯度 dĈ/dτ = s(û) − 2Σ r_Iᵀ(∂Ê_I/∂τ)q̂；
  - 精简的批量推理：共享稀疏模式、只存 α/β、不显式存 K；
  - 在共享主干上学一个对称半正定的 Neumann 作用 M = ΠBᵀBΠ，作 BDD 预条件，等算子冻结后再训；
  - O2 的 XP/XB 端口约定。

### E. 暂不做或否决的提议

| 提议 | 处理 | 理由 |
|---|---|---|
| SGNO、精确残差平滑、GenEO 粗空间、含精确 K 的 MgNO | 不进主线，只能作退路 A | 前向里有精确分解或残差迭代，不是完全学习 |
| q 路径加 LayerNorm | 否决 | 破坏对 q 的线性 |
| 满足严格最大值原理（收缩）的 q 路径 | 否决 | 精确 E 的 ∞-范数增益本来就大于 1；软/硬 Rayleigh 商相差 500–2000 倍，振幅有界照样可以有 1e2–1e3 倍的能量误差 |
| 用族描述量（τ 角点、rv、θ）做 FiLM | 否决 | 28 个族在 8 维 τ 空间里太稀；多刀切等后续几何没有这些描述量 |
| 现在就做构造性的 O_h 等变 | 暂缓 | 要重写 q 路径，先用增广 |
| FNO / GINO / 谱全局层 | 否决 | 在带掩码的高反差体上失效 |
| P2 的零和聚集和 l1 守卫 | 否决 | "非扩张"的说法不成立 |
| P5 的两连续体粗态；按中位数做的算子相关限制 | 否决 / 暂缓 | 限制本来就是归一化的加权平均，能再现常数；按中位数又引回了依赖具体几何的归一；幅度上限已并入 B1 |
| P6 按连通分量做刚体分离 | 只做诊断（A1） | 还没有岛存在的证据；无端口的浮岛没有处理 |
| G6 τ 抖动 | 暂缓 | 得到的不是 CutFEM 的 K；与快速换入冲突 |
| L6 方向级 CVaR | 否决 | 在 16 个样本的批里取前 4 个，会放大 fp32 梯度噪声；由 C3 替代 |
| 每 25 步换入；池 4–5 且每 50 步换入 | 否决 / 修改 | 装载和分解时间不够；显存峰值已达 28.4 GB |
| 把 fp64 刚体包装当作修复 | 只做 10 分钟检查 | 刚体部分的舍入约为 4e-6（相对值），远小于网络自身约 1e-4 的舍入 |
| 去掉 sin/cos 坐标 | 否决 | 绝对相位是真实信息 |
| 八分区灵敏度标签；学习型证书头 | 暂缓 | 先看更简单的办法效果如何 |
| L5 测试时自适应进主线 | 否决 | 每个几何要 15–120 s，结果会随几何和运行变化；只作标注的退路或诊断 |

## 第一部分 · 4. 实验顺序与判据

**阶段 0（现在，v1 正在跑）：** 只做 A0 和 A1，都是 CPU 或文件操作。

**阶段 1（第 1 万步验证出来时，建议事先写死以下分支）。** 那时的探针是 order[:12]，这些几何大约 6k 步前就已离开池子，所以测到的混有遗忘。

| 10k 的观测 | 解读 | 分支 |
|---|---|---|
| val 力类/支撑类均值 ≲5%，各几何的 max/median <3 | 跨几何的学习正常 | v1 跑完；重点转向 step-1 精度（C1–C3）和 B6；B1 作为 v2 的低风险默认项 |
| 少数留出几何出现灾难性误差（max/median >3，或力类均值 >30–50%） | 结构性尾部 | v1 继续作为对照；结束后优先对这些几何做 A3/A4/A5；然后跑 B1 的续训臂，若特征被证实是原因再加 B2 |
| val 整体偏高、探针明显更低（val/探针 >1.5） | 真实的几何差距，属于数据和覆盖问题 | B6 → C4 → C5 |
| val 和探针都高，且两者接近 | 分不清是遗忘还是容量 | v1 结束后用 A2 判断；若是遗忘，先做 C4，否则后面所有结构臂的比较都会被混淆 |
| 出现 NaN 或发散 | — | 停下来排查 |

20k 时再按同一张表复核一次。默认让 v1 跑完，把它作为 60k 训练计划下唯一的干净对照。

**阶段 2（v1 结束后，约 4–6 GPU 小时，不训练）：** A2–A9 加上 D1 的零参数证书。

**阶段 3（约 6–7 GPU 小时）：step-1 r2 的 A/B 实验。**
- 所有臂共用一个对照：d2 再训 1 万步，配比、种子相同，最高学习率 3e-4。不要用 e 臂作对照，因为它没有 face 类。
- 顺序：C2 → C1 臂 A → C1 臂 B → 按条件决定的 B4 / B5 / C3 尾损失。
- 判据：
  - 看 12 个门载荷的误差分布加压力测试，不要只盯 nbr_z 这一项；
  - 各类库误差变差不超过 5–10%；
  - 同时报告 μ 和 diag_lat 的拆分结果；
  - 胜出的臂用 2 个种子确认。

**阶段 4（每臂约 1.5 h）：step-2 续训臂。**
- 从 v1 最终检查点出发，LR ≤3e-4，训 1–2 万步，共用一个续训对照。
- 候选臂：B1、B2 臂 1、B6（需你同意）、B3（触发时才做）。
- 判据：
  - 按族配对比较，4 个 val 族里至少 3 个同向改善；
  - 看各几何的 max 和 p90；
  - 看 5 个固定几何上的 μ，以及证书的报警数。
- 注意：续训臂会低估从头训练的收益。

**阶段 5：**
- 重新准备数据：加入 C1 的新类、存 F、修复 NaN 几何，约 3–4 GPU 小时；
- 跑 v2 全程，约 5 h，包含训练器 v2 和所有胜出项；
- 在留出族上跑全学习晶格门，每个族用自己的 FULL 母胞；
- 测试族（development）只在最终配置定下后用一次。

**统计把握度：** val 只有 4 个族，族间差异远大于 0.3–0.6% 的梯度噪声。要在大约 10 个臂之间做选择，必须坚持"至少 3/4 族同向改善，胜出者用 2 个种子"，否则很容易在 val 族上过拟合选择。

## 第一部分 · 5. 需要你拍板的事

1. **v1 是否跑完。** 建议跑完，作为唯一的干净对照。只有在 20k 时证实遗忘非常严重的情况下，才考虑提前停下，把 GPU 让给诊断。
2. **O_h 增广是否从"第二轮"提前进入 v2。** 你定的朝向范围要靠它；它会改变训练分布。
3. **全学习晶格门是否作为附加报告指标**，以及是否据此调整 step-2 的精度目标。门本身的定义不动，除非你另作决定。
4. **是否批准一次全量重新准备数据。** 约 3–4 GPU 小时，磁盘增加 30–50%，内容包括：一致面力、按刚度比例的弹簧、粘接类、F、以及 5 个 NaN 几何的 fp64 重算。粘接构型与门不相交，这条约定也需要你确认。
5. **μ 和 μ₋F 是否从"只报告"升格为训练目标和选模型的依据之一**（门本身不变）。选模型的标准相应从"最大类均值能量"改为综合看灵敏度、p90 和 μ。
6. **证书报警后怎么处理：** 整个胞走退路 A，还是走标注的测试时自适应。两者都在主线之外。
7. **B1/B2 的影响。** 它们会让热启动后的数字发生变化。按"结果不能悄悄改变"的要求，它们全部以对照臂的形式引入；是否接受它们作为 v2 的默认项，由你决定。
8. **O2（XP/XB 端口约定）** 仍然留到 step 3 接整体求解时再比较。

**怎么读这张表：**

- **没有训练-留出差距，但这不能说明数据已经够了。**12 个训练探针是最早进池的几何，已经 7k–10k 步没训练过，测到的主要是遗忘。按综合建议第 4 节的分支，这一格是"两者都高且接近 → 分不清遗忘还是容量 → v1 结束后用 A2 判断"。
- **各几何之间差得很远，力类误差和几何大小强相关。**
  - FULL 母胞和大几何只有 0.04–0.12；
  - 薄、小、重度切割的几何超过 1：0029_d0_v2 为 1.21，0003_d1_v1 为 1.11；
  - 训练探针 0021_cover01_r1_rotswapxy 为 1.58，0010_d0_v1 为 1.56；
  - val 上 max/median ≈ 4，同时满足"结构性尾部"那一格。
- **池内训练损失停在平台上。**正在训练的几何，损失在 3k–10k 步之间停在 0.04–0.18（log ê），没有下降趋势，当时学习率约 1e-3。这与第 1 步"1e-3 伤害已收敛模型"的教训一致。
- **首次进池出现过灾难性方向。**第 1450 步有一个几何（0001_cover01_r2）进池时最坏比达到 15388，下一批损失 258、梯度范数 5.8e4。梯度裁剪兜住了，50 步内恢复。

### A1 统计（CPU，206 个几何）

- **median(d3) 跨几何相差 9.9 倍（p90/p10 为 3.65），超过 1.5–2 倍的判据 → B2 触发。**按"本几何中位数的 1%"定义的 weak 阈值，换算到绝对刚度后在 0.17–1.72 倍之间漂移；weak 比例在 12–20% 之间。
- **|M/vol| 从未超过 1。**B1 里的矩比截断不需要，删去。
- **没有划分泄漏：**15 个旋转包（0013、0021 两族）都与母几何同在训练集。

### 核对评审中的代码事实（逐条看过源码）

**属实：**
- ld = log(d3 / 本几何中位数)，weak = 本几何中位数的 1%，el_fringe / gp_fringe 由 weak 决定（models.py、prep_data.py）；
- GP 面模板只取第 1–3 层节点（owner 的两层加 neighbour 的中间层）；
- force / face / support 三类把端口上的光滑场直接当节点力，虚拟边缘节点也受力（prep_data.to_ports 只做 reshape）；
- 弹簧刚度 = α × 面平均对角，α ∈ [1e-2, 1]；
- 第 2 步的对抗搜索是 k = 8、4 次迭代，每次进池覆盖；validate() 只报能量类均值；best.pt 按最大类均值选；
- 残差下界的推导成立：端口精确时 r_I = K_II e_I，Δ(q) = r_Iᵀ K_II⁻¹ r_I，对任意 w 有 (wᵀr_I)² / (wᵀK_II w) ≤ Δ(q)。

**未能核实：**"设计文档 6.3 要求三分之一一致载荷"。设计文档里没有这一节，但"采样里从来没有按面力一致的载荷"这一事实成立。

### 据此调整

- **B2 由"待触发"改为"已触发"。**
- **B1** 去掉矩比截断，保留系数和延拓权重的有界化。
- **C4 训练器 v2 的依据更充分了**，因为已经看到平台和遗忘迹象。v1 仍按原建议跑完作对照，第 2 万步再复核一次。
