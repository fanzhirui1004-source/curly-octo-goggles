## 一、力学：S 到底是什么，几何怎么进来，难在哪

### 1.1 变分定义决定了一切结构性质

`gᵀSg = 2 × min{单胞应变能(+GP 稳定化能) : 边界迹 = g}`。

由此**全部**结构性质是恒等式而不是近似：对称、半正定、精确 6 维刚体零空间、`S ⪯ K_ΓΓ`、对任何 Galerkin 粗化 `S ⪯ S_粗`、以及 **Loewner 单调性**（`K₁ ⪯ K₂ ⇒ S₁ ⪯ S₂`）。

单调性有个我们之前没用上的推论：**变厚、加 GP、甚至激活一个新的切割单元，都是半正定加项**，所以 `S` 沿厚度是**跨越切换单调**的。这解释了两件观测：那次 +0.01% 厚度导致的 59.8% 是一个**单调跳跃**；跨 seat 谱是**单边**的（`μ_min ≈ 0.995`，见 `LIPSCHITZ.json`）。

### 1.2 条件数是薄板物理，不是数值毛病

`cond(A) ≈ (L/2h) × 12(L/t)²`。代入 `t ≈ 0.06–0.08`、`h = 1/32`：约 `6e4–1e5`，**括住了实测的 7.2e4**。

膜模态刚度 ∝ `t`，弯曲模态 ∝ `t³`，两族相差 `12(L/t)²` ≈ 2–3e3。那 188 个刚度 < 1e-6 的模态是**壳的近无伸长弯曲模态**——真实物理，任何稳定化选择都不会改变它们。

### 1.3 为什么软方向是"抵消"，以及这条决定一切

软模态刚度 = `gᵀK_ΓΓg − gᵀCg`，两项各自 ~`Eh`/节点，差 ~`Dk³`。比值 `ρ_J` 从 1（网格尺度）到 **1e3–1e4**（弯曲）。

这就是为什么：
- Frobenius 意义上占主导的近场，在能量度量下**最不重要**；
- 带状截断**在任何半径都失败**（实测 μ_max 恒在 59–144）；
- 按元素预测因子需要 `1e-4` 相对精度。

**而这是物理（由 `t` 和 `h` 决定），不是可以工程掉的伪影。**

### 1.4 远场低秩是 Saint-Venant

内部椭圆正则性 ⇒ 分离簇之间的 Green 核光滑 ⇒ 秩 ~`(log 1/tol)²`。力学上：超过一个衰减长度（~0.15–0.25 胞）只剩 **6 个合力 + 几个翘曲模态**。我们 9/11 实测的"前 8 个奇异值占 99.5%"就是 **6 + 2**。

近场是离散化的微分/超奇异算子加切割细节：满秩，不可压。

### 1.5 P9 放大阶梯 —— 本文最重要的一张表

参数误差如何放大成 `eps_op`：

| 学什么 | 放大因子 | 每参数需要的精度（±3%） |
|---|---:|---|
| 算子 `A` 的元素 | `cond(A)` = **7.2e4** | 5.5e-5（实测） |
| 因子 `R*` 的元素 | `√cond` = **269**（实测 111） | 1.2–2.7e-4（实测） |
| 尺寸 ℓ 的子域 DtN | `√cond_ℓ`：ℓ=1/2→45，1/4→11，**1/8→3** | 1e-3 ~ 1e-2 |
| **乘性局部物理场** | **1（精确）** | **3e-2 = 门本身** |

最后一行是恒等式：逐元素 `(1±δ)C` ⇒ 凝聚后 `(1±δ)S`，因为 Schur 补和求和保持 Loewner 序且齐次。

**结论：学局部，精确凝聚。** 学习的精度要求从 `1e-4` 降到 `3e-2`——三个数量级。

### 1.6 那次 59.8% 的机理，以及它到底是不是物理

硬活跃集规则下 `S(θ)` 是**分片实解析加 Loewner 单调跳跃**，跳跃间距在相对厚度上约 `1e-4`（水平集面移动 `1e-4 h` × 约 5e3 个切割单元）。每次跳跃加 ~`γEh ≈ 3e-6` 的稳定项：
- 对刚度在 `1e-6` 量级的方向，这是 **O(1)** 的白化变化 → 59.8%；
- 对物理方向，是 `O(1e-3)` → 端载柔度导数稳定到 0.023%。

**两者同时成立，不矛盾**（这正是审计第二条指出的）。

它**不是**薄连接物理：`t³` 铰链要响应快过 `τ` 2000 倍才能解释；而小于 `h/10` 的桥在离散里只表现为"体积分数 × E + GP"。

## 二、数学：正确的目标对象、度量、表示类

### 2.1 度量：Thompson / Loewner 夹逼，而且它精确可组合

`eps_op = max|μ−1|` 等价于 `(1−ε)A ⪯ Â ⪯ (1+ε)A`，是 Thompson 度量。它的关键性质：

> **模块证书即点阵证书。** 每个胞满足夹逼 ⇒ 任意点阵、任意载荷、任意边界条件的组装算子满足同一夹逼，柔度误差 ≤ `ε/(1∓ε)`。

而且它是**紧的**——邻居对一个胞施加的就是任意载荷。

反过来，**任何平均型损失只能给出 `max|μ−1| ≲ √(2dL)`**：`d = 12792`、`L = 1.27e-5` 允许 `eps_op` 高达 **0.57**。我们实测的 0.229 落在这个界内。这不是"经验上骗人"，是**理论上无法认证**。

### 2.2 抵消相干性 —— 这条杀死了直接预测路线

数学分析的 P3：

- 独立的逐元素相对噪声 `ε` → `eps_op ≈ 2ε√ρ_J ≈ 111ε`（与我们实测 `1e-4 → 1.11e-2` 精确吻合 ✓）
- **系统性的"近场 vs 远场"相对偏差 `δ` → `eps_op ≈ δ·ρ_J`**，所以 ±3% 需要 **`δ ≤ 3e-6 … 3e-5`**

**我们的噪声实验从没测过这个误差模式。** 我们测了独立噪声和块常数相干噪声（后者只贵 2 倍），但块常数噪声在每个块内保持了近/远场相干。**一个分别预测近场块和远场块的网络，其系统偏差正是 `δ` 型的。**

这是对 H 矩阵学习路线和逐元素路线的**第一性原理反对意见**，而且它是我们自己数据的推论。

> 只有**从内部求解生成远场**的表示，才免费获得这个抵消。

### 2.3 表示类的逼近率

| 类 | 收敛性 | 我们的实测 |
|---|---|---|
| 带状因子 | 不收敛（因子远场能量对数发散） | 任何半径 μ_max 59–144 ✓ |
| 稀疏多尺度 `TᵀDT`（块对角 D） | 小波对角预条件子，O(1) 谱等价，永远到不了 ±3% | oracle 底高 63–204 倍 ✓ |
| 低秩 + 稀疏 | DtN 的带外秩 ~`N^{1/2}log`，且单向低秩修正不能修错的带 | 可达性判据证否 ✓ |
| **H / H²** | **log-线性收敛** | 15% 稠密过 ±3% ✓ |
| **Schur 结构（collar + 约化内部）** | **抵消被生成而非存储；每参数相对误差 1:1 映射到 eps_op** | 2.3 万参数到 0.15 ✓ |

### 2.4 规范唯一性

| 对象 | 规范 | 能否作回归标签 |
|---|---|---|
| Cholesky（固定序） | 唯一 | 可以（Lipschitz 常数 ~log d） |
| **`A^{1/2}`** | **唯一，连续，置换等变** | **可以** |
| SVD 因子 | 符号 + 重奇异子空间旋转 | **不可以** |
| `(T, D)` 对、低秩 `M`/`U` | 连续规范群 | **不可以**（2.47× 损失失真就是症状） |
| 局部单元矩阵 / 材料张量 | 固定局部基下唯一 | **可以** |
| 子空间 `span(V)` | 只有 span 进入 | **可以**（用子空间对齐损失） |

### 2.5 样本复杂度：全局对象 vs 局部对象

33（或 1024）个几何 × 48 对称 ≈ 每个几何轴 **3 个点**（8 个厚度角点 + 4 个切面参数 ≈ 9–12 维）。

- **全局对象**（`S` 或 `R*` 的元素）：3 个点/轴，要 1e-4 的相干性 —— 不可能
- **局部对象**（单元矩阵、GP 面、局部张量）：每个胞 ~7500 个切割单元、~1100 个粗格，是一个 6–8 维光滑映射的 **1e5–1e7 个样本**

**这是权重共享能不能救我们的分水岭。** 对全局对象做空间权重共享，偏差恰好落在决定性的模态上。

## 三、网络原理

### 3.1 分工原则（NN 分析 P1）

> 网络只预测**几何的局部函数、量级 O(1)、精度需求 1e-2** 的量；
> 精度关键的全局部分（产生抵消的那次消元）是模型内部的**精确 fp64 线性代数**。

`S = K_bb − K_bi K_ii⁻¹ K_ib`：所有非局部性都从 `K_ii⁻¹` 进来。分别预测两项要 1e-4/元素；**计算这个差不需要**。

### 3.2 结构性质必须在参数化里，不在损失里

SPD、精确刚体零空间、立方群等变、Galerkin 单调性——全部由构造保证。

我们自己的证据：**刚体不变性由构造保证，是唯一消掉 38.8% 纯对角吸引子的东西**（10 轮实验贴在这个数上）；而 V1 只用增广而非结构等变，在未见的对称帧上数值奇异。

### 3.3 V1 失败的诊断

V1：六面 65×65 图像 CNN，感受半径 0.23，59 万参数，26 标签，训练和留出**同为 27%**（欠拟合）。

力学分析给出机理：**全局弯曲刚度依赖到处的厚度**，六个面的图 + 半径 0.23 的感受野**在表示能力上就装不下**。这不是数据问题，是输入和感受野问题。

### 3.4 损失

必须是 sup 型，且**两侧**。我们跑过一次单侧极端项：`μ_max` 15→5 而 `μ_min` 0.13→0.05 —— 这正是容量受限类上单侧 sup 损失的预期打地鼠行为。

可用形式：
- 两侧 log-sum-exp 覆盖白化铅笔两端各 k 个 Ritz 值（warm-start block Lanczos，软端在 `Â⁻¹` 上做）
- Schatten-2k 矩（`2k=32` 时上界因子 1.34），Hutchinson 探针估计
- Loewner 对数障碍 + `ε` 同伦（内点法路径跟踪）

梯度用 Hellmann-Feynman（特征向量 detach）。对凝聚型模型，`dμ/dθ` 就是**该模态 K-调和延拓在每个单元的应变能密度**——伴随灵敏度，量纲良好且可解释。

### 3.5 精度

主干和头 bf16/fp32；**所有加法形成、凝聚、Cholesky、白化用 fp64**。绝不在 fp32 里加法形成 `A`。

## 四、文献告诉我们什么

### 4.1 最接近我们交付物的三篇

**Parish, Lindsay, Shelton, Mersch (2023/2024), "Embedded symmetric positive semi-definite machine-learned elements", arXiv:2307.05434 / Comput. Mech. 74:1357.** 把内部区域的静力凝聚学出来，装配进外部 FE。两个变体：无约束的位移→力回归器，和直接学 SPSD 刚度矩阵（即 Schur 补）。**结论是 SPSD 变体对耦合求解的正确性是必需的**，无约束回归器破坏求解。这和我们"结构必须在参数化里"完全一致。他们的内部几何固定，没有几何泛化问题。

**Ouyang, Shin, Liu, Lu (2025/2026), "Neural-operator element method (NOEM)", arXiv:2506.18427 / Nat. Comput. Sci.** 用一个预训练神经算子代替整个子域，输入边界位移、输出子域总势能，刚度 = 学到的能量的 Hessian，然后按变分框架装配。**监督能量而不是矩阵元素**——规范自由、可组合、可以在随机和对抗迹向量上评估，正是 `eps_op` 需要的。

**Beatson, Ash, Roeder, Xue, Adams (2020), "Learning Composable Energy Surrogates for PDE Order Reduction", NeurIPS 2020, arXiv:2005.06549.** 超材料胞的可组合能量代理。他们做**装配载荷上的数据聚合**：训练后用代理装配，收集实际出现的界面位移模式，把最坏误差方向加回训练——一个便宜的、物理驱动的最坏方向代理。

### 4.2 为什么直接学 DtN 很难（有理论）

**Ling, Ying, Zhou (2026), "Principal-Part Decomposition for Neural Operator Learning of Dirichlet-to-Neumann Maps", arXiv:2606.25952.** 核心论点：**DtN 是非光滑化的（+1 阶拟微分算子），无界的主部必须解析处理，只有紧的余项能学。** 他们把 DtN 拆成几何无关的奇异主部（精确 FFT）+ 光滑的几何相关余项（低秩 DeepONet），精度和 OOD 鲁棒性都优于直接神经算子基线。

**这直接解释了 V1 的欠拟合，也给出了 fallback 设计：`S = S₀(计算出的主部) + 学习的乘性修正`。**

**Mishra 等 (2024), "Data Complexity Estimates for Operator Learning", arXiv:2405.15992** 给出算子学习的数据复杂度下界；配合我们"3 个点/几何轴"的事实，全局插值路线的数据需求是不可满足的。

### 4.3 静力凝聚的最优局部空间（这条最重要）

**Smetana & Patera (2016), "Optimal local approximation spaces for component-based static condensation procedures", SIAM J. Sci. Comput. 38(5):A3318.** 用**转移特征问题**（transfer eigenproblem）构造端口/界面约化的**最优**局部逼近空间，并证明**指数收敛**。

**这正是我们需要的工具**：它回答"collar + 粗核的 Kolmogorov n-宽度是多少"、"要多少个富集模态才能让 Loewner 底降到 0.03 以下"——**在任何训练之前，用我们已有的精细因子就能算。**

配套：**Huynh, Knezevic, Patera (2013), "A static condensation reduced basis element method", ESAIM M2AN 47(1):213** 给出端口约化的框架和后验误差估计。

### 4.4 H 矩阵的理论支撑与神经类比

**Bebendorf & Hackbusch (2003), Numer. Math. 95:1**；**Faustmann, Melenk, Praetorius (2015), Numer. Math. 131(4)**：椭圆 FE 矩阵的逆和 Schur 补存在 H 矩阵逼近，**远场块数值秩有对数界**。
**Xia, Chandrasekaran, Gu, Li (2010), SIAM J. Matrix Anal. Appl. 31(5)**：离散椭圆算子 Schur 补非对角块的数值秩。
**Fan, Lin, Ying, Zepeda-Núñez (2019), "A multiscale neural network based on hierarchical matrices", Multiscale Model. Simul. 17(4)**：H 矩阵结构的神经网络（MNN-H）。
**Li, Kovachki, Azizzadenesheli, Liu, Bhattacharya, Stuart, Anandkumar (2020), "Multipole Graph Neural Operator", NeurIPS 33**。
**Chen, Owhadi, Schäfer (2021), "Sparse Cholesky factorization by KL minimization", SIAM J. Sci. Comput. 43(3)**：稀疏 Cholesky 的筛选理论——但它对**边界限制**的算子不适用，这是我们 `TᵀDT` 失败的理论原因。

一条**负面**结果值得记：**"Message-Passing GNNs Fail to Approximate Sparse Triangular Factorizations" (2025), TMLR, arXiv:2502.01397** —— 消息传递 GNN 在表达能力上无法逼近稀疏三角分解。这直接反对"用 GNN 回归因子"。

### 4.5 CutFEM 的几何连续性

**Badia, Verdugo, Martín (2018), "The aggregated unfitted finite element method", CMAME**；**Badia, Neiva, Verdugo (2021/2022), "Linking ghost penalty and aggregated unfitted methods" / "Robust high-order unfitted FE by interpolation-based discrete extension"**：聚合方法用**离散延拓**代替罚项，是我们那个"内部延拓原型"的正规版本。
**Burman, Hansbo, Larson (2022), arXiv:2205.01340**：locking-free ghost penalty 的设计。
**Burman, Elfverson, Hansbo, Larson, Larsson (2018), "Shape optimization using the cut finite element method", CMAME**；**Berggren (2023), "Shape calculus for fitted and unfitted discretizations", arXiv:2210.10411**：**unfitted 离散的形状导数**——直接相关于我们"算子导数不稳定但任务导数稳定"的观测。
**Neiva & Badia 等 (2025), "Level-set topology optimisation with unfitted finite elements and automatic shape differentiation", CMAME**：unfitted + 自动形状微分的拓扑优化，正是我们的下游。
**de Prenter, Verhoosel, van Brummelen, Larson, Badia (2023), "Stability and conditioning of immersed finite element methods", Arch. Comput. Methods Eng.**：浸入式方法的条件数分析与补救。

### 4.6 拓扑优化对代理精度的实际要求

**Amir, Bendsøe, Sigmund (2009), "Approximate reanalysis in topology optimization", IJNME 78(12)**；**Amir (2021), "Efficient stress-constrained TO using inexact design sensitivities", IJNME**：**不精确灵敏度在 TO 中可用**，但要有控制。
**Alexandrov, Dennis, Lewis, Torczon (1998), "A trust region framework for managing approximation models", Struct. Optim. 15:16**：信赖域管理代理模型——**收敛性有保证**的框架。
**Keil & Ohlberger 等 (2021), ESAIM M2AN 55**：信赖域约化基。
**Smetana 等 / Ferrari & Sigmund (2024), "One-shot procedures for efficient minimum compliance TO", SMO**。

**这些合起来说明：mode A + 信赖域 + 教师检查点是有文献支撑的部署方式**，不需要模块门本身保证 TO 收敛。

## 六、四条路径的裁决

### 路径 1：H² 平方根神经算子（H2-SQRT）—— 有条件存活，作并行对照

学 `A^{1/2}` 的 H² 表示（`Ŝ = Z R̂² Z`）：PSD、刚体不变、**规范唯一**（SPD 平方根唯一且连续、置换等变，优于 Cholesky）、乘性误差不被 `cond` 放大、立方群可用 frame averaging 精确等变。

**我补的最强反对**：§2.2 的相干性。它分别发出近场块和远场块，系统性近/远偏差要控制到 `3e-6…3e-5`，比已展示的算子学习精度（1e-2…1e-3）**高 3–4 个数量级**。这很可能是致命的，而且**可以在训练前一天内测出来**（见 §9 实验 B）。

次要反对：`A^{1/2}` 的 H² 可压缩性从没测过（我们测的是 Cholesky 因子）；每胞 ~1e5 个光滑耦合数要 1e-4 相对精度。

### 路径 2：ReCell —— 推荐

精确细 collar + 计算出的富集 Galerkin 核 + 学习的 Loewner 有界乘性本构修正 + fp64 精确凝聚。

**为什么它是唯一避开 §1.5 和 §2.2 的路径**：学的量放大因子恰好是 1，且抵消由消元**生成**。

**我补的最强反对**（按严重程度）：
1. **运动学下界可能降不下来。** 固定一层 collar + Q1 核已证 `μ_max ≥ 1.111`。富集后能否到 0.03？软模态沿薄曲线变化并跨厚度振荡，固定几何粗基最多只装下 72% 能量（9/12 覆盖检查）。**这是第一杀判据，而且训练前可算**（Smetana–Patera 转移特征问题）。
2. **成本没量过。** 今天 30 s，目标 2–5 s。若打不过 31.85 s，整条路没有意义。
3. **可辨识性。** 多种内部配置可给相近边界响应，学到的张量未必是几何的唯一光滑函数。
4. **灵敏度从没测过**，而 TO 消费的是它。

### 路径 3：算子学习优先（查询/注意力式）—— 死

提案 agent 没跑成，但结论可以从 §2.2 和 §2.5 直接得出：查询式解码器按 `(i,j,geometry)` 预测元素，是**全局对象上的权重共享**，偏差恰好落在决定性模态上；且 `1e-4`/元素 × 8.2e7 个元素 × 3 点/几何轴。**排除。**
（`Message-Passing GNNs Fail to Approximate Sparse Triangular Factorizations`, TMLR 2025 是同方向的负面结果。）

### 路径 4：基础优先（先修教师）—— 部分并入推荐路径

审计第二条已证明"必须先重做教师"不成立（任务级导数稳定到 0.023%）。但**是否需要重做由一个 γ 扫描决定**（§9 实验 A），不由信念决定。标签重生成只要 9 小时，不是障碍。

## 七、推荐路径

> **放弃直接预测 `S` 或其因子。改为：网络预测局部物理量（乘性 SPD 本构修正），由精确 fp64 凝聚生成 `S`。**
> **H² 作为部署格式和并行对照保留，不作为学习目标。**

## 八、三个必须由你决定的问题

**(1) 推理时允不允许一次约化内部求解（目标 2–5 s/胞）？**
我的建议：**允许。** 这是 §1.5 放大阶梯的全部价值所在——不允许的话只剩路径 1，而 §2.2 预测它过不了软模态。若 0e 实测打不过 31.85 s，再重新考虑。

**(2) 交付契约是模块级 Loewner 夹逼，还是登记范围的任务级？**
我的建议：**主契约用模块级**（它精确可组合，是唯一有组合定理的），**任务级作补充证据**并登记几何/载荷/灵敏度范围。理由是审计第四条：柔度一阶敏感，我们那 0.3% 是构造相关的。

**(3) 若 0a 显示决定性方向由稳定化定义，是否重生成标签（9 小时）？**
我的建议：**是。** 用 C¹ 混合的聚合稳定化（Badia–Neiva–Verdugo 的离散延拓，把硬分类换成光滑权重），重新通过 Tet10 验证 + 导数测试。代价很小，收益是让目标本身可学。

## 九、一天内就能做的证伪实验

### 实验 A（分钟级，最决定性）：γ 扫描

在 0328 上用 γ = 1e-3 和 γ = 1e-5 各跑一次教师，算两个教师之间的白化谱。

- **若 `eps_op` > 0.1**：±3% 的模块门在要求复现一个**任意的稳定化参数**。契约或标签必须先改，任何学习都是在拟合噪声。
- **若 `eps_op` < 0.03**：决定性方向是物理的，当前门有意义，标签不必重做。

成本：两次教师运行（64 核上各约 15 分钟）+ 一次白化评价。**这一个数决定后面所有事情的前提。**

### 实验 B（小时级）：近/远场相干性 oracle

拿那个已经过 ±3% 的 H 矩阵因子，分别给**近场块**和**远场块**加**独立的光滑相对场**（1e-2 / 1e-3 / 1e-4），量 `eps_op`。

- **若 1e-4 的近/远偏差就让 `eps_op` > 0.1**：§2.2 的预言成立，**直接学习 H 矩阵/因子的路线在训练前就死了**，路径 1 关闭。
- **若要到 1e-3 才失败**：路径 1 值得作并行对照。

这个实验补的正是我们 `PER_ENTRY_ACCURACY` 里缺的那个误差模型（T1 的真正版本），而且**全部用现有工具**。

### 实验 C（小时级）：Loewner 底扫描的第一格

用 Smetana–Patera 转移特征问题，在 0328 上算 collar 深度 1、核 Q2 + 8 个富集模态的 `η`。

- **若 `η` 已经 < 0.05**：推荐路径的第一杀判据通过，直接进阶段 1。
- **若 `η` 仍 > 0.1**：加深 collar 和加富集，看趋势；若到 8e4 自由度还下不来，推荐路径死，回路径 1（前提是实验 B 放行）。

## 十、一句话

**六天证明了"直接预测 `S` 或其因子"要求 1e-4 的元素精度和 1e-5 的近/远场相干性，而这个要求来自 `t` 和 `h` 决定的 `cond(A)`，工程不掉。唯一把精度要求降到门本身（3%）的办法，是让网络只预测局部物理量，让消元去生成抵消。**
