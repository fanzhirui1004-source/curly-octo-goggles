## 1. 项目目标与术语

**目标。** 学一个几何条件化的界面算子 Ŝ(θ)，替代 TPMS P 型薄板模块的 CutFEM 界面 Schur 补（静力凝聚后的算子）。最终用途：装配成点阵接入拓扑优化。

**教师。** n = 32 背景网格，Q2 单元，ghost penalty。典型模块（seat 0257）：细系统 316488 自由度，内部 297450，界面 q = 19038，凝聚比约 16:1。教师一个模块：拼装 0.6 s，几何与因子准备约 29 s，316k 维分解 66 s，导出 Schur 补共约 95 s。数据集只存凝聚后的界面算子 S（q 在 1.3 万到 2.6 万之间）。教师视为准确，不做容差校准（已决定）。

**商空间。** 六个 Householder 反射构成正交的 B（行正交，核 = 刚体迹），A = B S Bᵀ（d = q − 6），教师因子 R*（A = R*ᵀR*）由 dense_reference 生成。学生比较对象是 Â = B K0 Bᵀ；物理算子 Ŝ_phys = Bᵀ Â B（有刚体核）。装配必须用 Ŝ_phys 或等价的投影形式，不能直接装 K0。

**学生表示（统一公式）。** K0 = Lᵀ(I − M G⁻¹ Mᵀ)L。
- L：面上节点 DOF 的带状上三角因子（物理半径 r_near 内的节点对，包内节点顺序），现有约 880 万非零元（q≈20700, r=0.2）。
- M：面 DOF 到内部变量的耦合（q × k）。
- G：内部矩阵。B1：G = I + MᵀM（现有）；B2：G = K_loc + MᵀM（粗内部）。
- 等价的能量形式：½xᵀK0x = min_z ½‖Lx − Mz‖² + ½zᵀ(G − MᵀM)z。正定由构造保证（G ≻ MᵀM）。
- 白化谱 μ：W = R*⁻ᵀ Â R*⁻¹ 的特征值，μ_i 是学生相对教师在第 i 个广义方向上的刚度比。

**监督（不变）。** 精确 log-det 散度 D = tr(A⁻¹Â) − log det(A⁻¹Â) − d = Σ(μ − log μ − 1)，无探针；tr 用 Z = R*⁻ᵀB 精确算（‖(I+MMᵀ)^{-1/2} L Zᵀ‖²），log det Â = 2Σlog L_ii − log det G + log det(Nᵀ K0⁻¹ N) − log det(NᵀN)（N 刚体模态；B2 需再加 log det K_loc 的对应项）。加极端模态项：对 W 与 W⁻¹ 各维持 8 维块做热启动块幂迭代，Ritz 值用 φ(μ)=μ−log μ−1 进损失，权重 0.1。训练中的 Ritz 只能否决不能放行。

**验收。** 冻结模型完整广义谱（spectrum_eval.py，CPU float64）。工作门槛 μ ∈ [0.9, 1.1]；目标 μ ∈ [0.97, 1.03] 且 D/d < 1e-4。同时报告 e_A = ‖Â−A‖_F/‖A‖_F、白化矩阵对称性缺陷、极端特征对残差。位移度量 E（ghost penalty 带）只作报告项，不作主要杠杆。

**分工。** 后端 = 系数张量 → 算子（表示类、正定构造、商空间、目标、求解、验收）。前端 = 几何 → 系数张量的网络。**当前阶段只做后端**：用单标签自由优化检验容量，并按可学性原则设计表示。可学性三条件：系数由几何唯一确定（规范固定）；主要由局部几何决定；只需 1e-2 到 1e-3 相对精度。三个命题分开测试：正能量表示存在、自由优化能拟合、系数能局部预测。

## 5. 已确定的事实与原则（不要再重推）

1. 前向 KL 散度方向不是主要问题；极端项补的是 1/d 稀释。
2. 训练中 Ritz 值只能否决不能放行；放行用冻结模型完整谱。
3. 消元序（Morton/RCM/光栅）与带宽都不改变带状因子类的极限。
4. 三角因子的元素依赖消元序，不是几何的光滑函数，这是前端目标的负担，后端测试不受影响。
5. 教师的 95 秒里 66 秒是 316k 维分解，拼装只要 0.6 秒 → 细尺度局部问题便宜，可用于局部构造与局部标签（待查接口）。
6. 运行时按定义矩阵向量作用，不形成稠密 Schur 补；不凝聚装配的等价性已证明（投影 Π_m = B_mᵀB_m 作用在 L 之前，各模块内部变量独立最小化后恰为 Σ C_mᵀ Ŝ_phys,m C_m）。
7. 前端不可能靠回归近场刚度元素得到软模态（抵消比 1e3–1e4）；但这不等于"任何刚度形式都不成立"——**需要保持相对能量结构的参数化：固定几何决定的相容/应变算子，学习其上的正能量权重或小型本构矩阵**。
8. 装配用 Ŝ_phys = BᵀÂB 或等价投影形式；直接装 K0 会引入假刚体刚度。

## 6. 外部审计（GPT Pro）后的修订方案

### 6.1 审计要点与采纳
- B2 代数上仍是 B1：X = M K_loc^{-1/2}，rank(LᵀL − K0) ≤ rank(M)；M 只连第一层内部节点时，软化通道数由直接耦合的内部自由度决定（n=16 约 600 节点 ≈ 1800 DOF，与约 1000 个软方向同量级）。**实验必须记录：内部自由度、直接耦合自由度、rank(M)。** 改法：耦合两层或半径 0.15。
- "局部块准则全谱准"只在同一运动学空间成立，且要求 Loewner 相对误差；粗内部若是 Galerkin 子空间则 S_H ⪰ S_h，超出量 = ‖u_H*−u_h*‖²，块再准也不消；自由学习的超单元族只是待验证表示族。
- 稀疏结构不锁死规范（按节点分块的可逆变换保持稀疏）；规范要靠物理坐标、固定应变算子、刚体作用固定。
- 局部性的检验是"局部构造闭合"（用有限邻域细尺度局部问题确定性构造块，邻域逐步扩大，看凝聚后谱何时接近全局自由拟合），不是对称帧拟合。
- 粗网格：嵌套规则背景 + 真实材料连通性（同一格子内不连通材料不共用自由度，穿格薄连接不丢）+ 必要局部运动学富集；不自由移动节点；h ~ t 只是经验起点。
- 材料矩阵在应变空间正定；位移块半正定（刚体核）。
- E2 触发：先检查基线 C_L = BLᵀLBᵀ 是否已低于目标下界；秩障碍 #{λ(H_L)>β} ≤ rank M；新增列不可零初始化。
- "6000 步"只称该预算下的误差，并列墙钟、系数数、内部规模、作用成本。
- 对任何过门的拟合做敏感性检查：固定规范与结构，系数加 1e-3、1e-2 扰动看完整谱，排除"拟合到 3% 但系数要准到 1e-6"。
- 混合耦合"不差于 B1"只在写出显式嵌入时成立。

### 6.2 B2 v1 的明确定义（待实现）
- 内部节点：n = 16 嵌套规则背景网格角点；只保留与材料相交的格子；用细网格材料连通性判定格内连通分量，不连通分量各自建节点集；全局坐标，单位与面一致。
- 块：K_c = C_cᵀ D_c C_c，C_c 为格子固定 Q1 应变算子（由几何算出），D_c 为学习的 6×6 对称正定材料矩阵（可按格内材料几何初始化，log 参数化）；位移块半正定，刚体自动不做功。K_loc = Σ_c 拼装。
- 过渡层（最没把握）：面 DOF 到邻近两层内部节点的耦合 M，写成"固定插值关系 × 学习权重"；运动学要单独写清并测试。
- 面因子 L：容量参照阶段保持自由因子；v2 再改为固定应变算子加权重。
- G = K_loc + MᵀM；log det K0 = 2Σlog L_ii + log det K_loc − log det G（+ 刚体修正）；迹项形式不变。
- 规范：由上述固定坐标与算子锁定，无剩余自由度。
- 装配：投影后的凝聚算子，或按审计证明保留内部求解。
