## 为什么不需要网络（方向性的结论）

1. **单元刚度**：单元在自身能量范数下误差 ≤ ε，整体就保证在 ±ε 以内。回归式的误差会被放大（见上表），
   确定性几何积分天然半正定、刚体零空间精确、误差二阶收敛，GPU 上 1 万个单元 1–3 秒。
2. **查询**：GPU 稀疏 Cholesky 精确且毫秒级。原先设想的“学一个更强的平滑器把 186 层压到几十层”，
   即使做成也比直接分解慢两个数量级。

## 需要你拍板的事

1. **是否正式放弃神经网络路线**，把“可复用的结构化算子”定为 {P、GP、A/C/D、cuDSS 因子}，查询做前代回代。
   我的建议是放弃；如果一定要用网络，剩下唯一的位置是替代慢的 Python 环节，但那些是确定性代码，重写比学习更合适。
2. **compile_trace（迹坐标）怎么提速。** 它 93% 的时间在精确有理数逐行消元，主元按精确大小选。
   两个选项：(a) 用编译语言照原规则重写，坐标与现在逐位相同；(b) 换一个浮点可算的坐标约定，快得多，但边界坐标会变，
   需要做一次坐标迁移（冻结代码里已有迁移工具）。
3. **精度档位**：有效分辨率 8（最差 1.6%，最快）还是 16（实测最差 0.4%，单元积分约乘 4，编码最多约 17 s）。
4. **第二批数据的用途**：原计划用来训练单元网络；现在建议改作验证集（36 个几何，保留体积 0.008–0.99）。
