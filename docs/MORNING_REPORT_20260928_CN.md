## 3. P2 提速

- **三个默认关闭的新开关：**
  - `OPL_KE_SYMV`：上三角打包的 fp32 单元刚度 Triton 核；
  - `OPL_COARSE_INV`：粗求解用显式 fp32 逆；
  - `OPL_KE_SYMV64`：fp64 单元刚度也走打包核。
- **效果：** Ŝq 在 B=3 下从 79.7 ms 降到 61.1 ms（−23%），输出差异在噪声范围内（4e-8）。
- **92 胞第 4 轮（三个开关全开）：** 比第 3 轮慢。第 0 次迭代 63 分钟还没完成，第 3 轮全程只用了 28.6 分钟。已中止。
  - **推测原因：** 打包核只在 B ≤ 12 下调过参。格架求解的融合转置用 2B = 32 列，寄存器块会溢出。
  - **已修复：** 超过 16 列时按 16 列一块分批调用。
  - **待办：** 微调结束后自动跑各开关在 B = 1–64 下的计时，只打开在 16 和 32 列下都更快的开关，再重跑 92 胞（round4b）。
