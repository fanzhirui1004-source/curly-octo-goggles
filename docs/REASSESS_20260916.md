# 重新评估：两个便宜的检验推翻了当前方向的两条支柱

日期 2026-09-16。来源：E1-B 实测 + 九路独立对抗核对（`evaluate-operator-proposal` 工作流，9 个 agent，85 万 token）。

---

## 一、纯块对角被证否，没训练一步

oracle 底 `D* = Σ_b logdet C_bb − logdet C` 是该 `T` 与该分块下**任何** `D` 都无法突破的下界。
把门翻译成对它的必要条件（`f(t) = t − log t − 1`）：

```
所有 μ 在 ±3%   =>  D/d ≤ max(f(0.97), f(1.03)) = 4.5921e-4
所有 μ 在 ±10%  =>  D/d ≤ max(f(0.90), f(1.10)) = 5.3605e-3
```

真实教师 seat 0328，`T = I`（即纯块对角）实测：

| 块大小 | oracle 底 D/d | 相对 ±10% 必要条件 |
|---:|---:|---:|
| 8 | 1.0921 | **204 倍以上** |
| 24 | 0.7378 | 138 倍 |
| 64 | 0.3355 | 63 倍 |

每个 3 到 7 秒。**纯块对角在商坐标下被证否**，不需要任何训练。

这正是 oracle 底该起的作用，而且它比训练便宜三到四个数量级。

## 二、成本动机是错的：在这个尺度上，作用从来不是瓶颈

`d = 12792` 时：

| 量 | 值 |
|---|---:|
| 稠密 `Â` 存储 | 1.31 GB |
| 一次稠密 GEMV | 3.27e8 flops |
| fp64 计算时间 | 0.205 ms |
| 带宽下界 | 1.007 ms |
| **我实测的多尺度 apply** | **137 ms** |

**结构化算子比直接稠密乘慢约 136 倍。**

而真正贵的是 PARDISO 凝聚：31.85 s。

所以：**「用多尺度结构让算子作用变快」解决的是一个在这个尺度上不存在的问题。**
网络要省的是**形成** `S` 的成本，不是**作用** `S` 的成本。一旦拿到 `S`，作用它只要 1 毫秒。

这条推翻了新形式的主要成本论证。它没有推翻「网络预测算子」这个目标，但它说明
交付物应当按**每几何 setup 成本**来评判，而不是按「快速作用」。

核对还指出我实测的 137 ms 里大部分是实现开销（Python 循环遍历 533 个块、
`sparse_coo` 每次重建），不是本质成本。但即使优化到理论值，多尺度结构在 d=12792
也赢不了一次 1 ms 的稠密乘。

## 三、散度目标系统性地放过软方向，这解释了我们全部的失败史

`φ(t) = t − log t − 1` 严重不对称：

```
φ(86)     = 80.5      过硬方向被近似线性惩罚
φ(0.0695) = 1.74      过软方向只被对数惩罚
```

所以**散度最优的拟合会优先留下软尾巴不管**。

对照我们的实测：截断教师因子 `μ` 到 86–88；旧后端 `μ_min = 0.0695` 而散度一路在降；
可达性诊断说低秩项只能变软。三条连起来是同一件事：

> 我们用的目标对「变软」几乎不罚，而我们的参数化又只能变软。

核对进一步证明了散度最优与最坏方向最优**结构上不同**：散度最优恒满足 `Σμ_i = d`（均值 1），
而 `max|μ−1|` 的最优满足 `μ_max + μ_min = 2`。二者一般不重合。反例：散度最优
`D = 37.49, μ ∈ [0.0015, 3.73], max|μ−1| = 2.73`；乘一个标量 `s = 0.5358` 后
`D = 41.33`（差 10%）但 `max|μ−1| = 0.9992`（**好 2.7 倍**）。

**免费的推论**：任何拟合之后，乘上标量 `s = 2/(μ_max + μ_min)` 都严格改善 `max|μ−1|`。
这是一个标量，零成本，应当写进评价流程。

## 四、提议的作用损失不是解药，它就是同一个平均

`L_action = ‖H − I‖²_F / d = mean(μ_i − 1)²`。而 `f(t) = (t−1)²/2 + O((t−1)³)`，
所以在门附近

```
L_action = 2 × (D/d)
```

**逐点相等到三阶。** 换成作用损失不引入任何最坏方向信息，还去掉了散度在 `μ → 0` 处的对数势垒，
而那正是我们失败的一侧。

结论：要过 `ε_op` 的门，训练信号里必须有显式的极值项（对 `H − I` 做 Lanczos 取当前极端方向，
或 log-sum-exp 型替代），不能靠任何 L2 平均。

## 五、局部 `T` 会让预测的柔度也带状，这是在已知绑住的那条轴上倒退

若 `T` 是 L 层、每层半径 r 的局部块之积，则 `T⁻¹` 也是局部的、半径 ≤ L·r
（提升层的逆是 `I − K`，同支撑）。于是

```
Â = TᵀDT      带状
Â⁻¹ = T⁻¹D⁻¹T⁻ᵀ  也带状，半径约 2Lr + b
```

**带状的逆意味着预测的柔度在半径之外恒等于零。** 真实柔度不是。而我们测出来绑住的恰恰是
软方向（柔度大的方向）。所以局部 `T` 在这条轴上是倒退。

要避免，`L·r` 必须大到跨越整个区域——而那时成本论证又回到第二节。

## 六、还有三条我认为必须在继续之前处理

**第一，验收门可能低于标签自身的可表示下界。** `docs/STORAGE_FLOOR_ACCEPTANCE_20260914.md`
实测 seat 52 有两个软方向的 `E/N` 是 3.04 和 3.58，即在存储因子 `R` 的 FP64 舍入下界的三倍以内。
在那些方向上，标签本身撑不起 3% 的断言。应当在 `H` 的特征基上算每方向下界，登记「可判定性」门槛。

**第二，从未测过几何到算子的映射是否足够光滑。** 仓库自己的记录：0.01% 的厚度扰动曾让
一个完整边界方向的刚度变化 59.76%，起因是一个材料体积分数约 5.6e-15 的背景单元激活了三条新的
ghost 面。**如果这个映射的 Lipschitz 常数足够大，没有任何编码器能在 3% 的容差上工作。**
便宜的检验：对有参考因子的 12–32 个 seat 两两算交叉白化谱
`ε_op(i,j) = max|eig(R_i⁻ᵀ A_j R_i⁻¹) − 1|`，对几何距离作图。这应当排在 E0 之前。

**第三，部署模式从未固定，而两种模式的门差 30 倍。**
模式 A（代理）：装配后直接用 `Ŝ`，接受 Loewner 误差 ε，`±3%` 门成立。
模式 B（预条件子/内迭代）：精确性来自迭代，门应换成目标迭代次数，
而现有的自由稠密因子在 `ε = 4.68%` 下可能**已经够用**。

## 七、还站得住的

- **可达性诊断**：22 秒证否旧后端的 `L`。
- **oracle 底**：3–7 秒证否纯块对角。这两个工具本身是本轮最大的收获。
- **`ε_op` 是正确的验收量**，且 `D/d` 只能当训练诊断。
- **四态判定与冻结检查点纪律**。
- **分阶段验证链的骨架**（每阶段保留上一阶段作对照）。
- **E0-A/B/C 的实现正确性**：恒等式全过，`det T = 1` 到 2.5e-16，
  且 E0-B 证明了把 `D` 用闭式消掉能把结果改善两个数量级（`D/d` 3.206e-5 → 3.234e-7）。

---

## 八、我现在认为该做什么

按「最便宜且最能证否」排序，全部在写任何新网络之前：

1. **交叉几何 Lipschitz 常数**（第六节第二条）。如果不够光滑，整条路线的前提就不成立。
2. **固定部署模式**（第六节第三条）。它决定门，而门差 30 倍。
3. **把自由稠密因子在全程 fp64 下重跑**。它的停滞被仓库自己归因于「fp32 线搜索返回零步长」，
   而不是表示能力。如果 fp64 下它过 ±3%，那么目标门对无约束因子是可达的，
   后面每一个结构化类都有了明确的对照上限。
4. **给训练信号加显式极值项**，并在任何拟合后免费应用 `s = 2/(μ_max + μ_min)` 的重标定。
5. oracle 底继续作为结构筛查，但**筛查的对象要改**：不是「怎样让作用变快」，
   而是「怎样让每几何 setup 变便宜」。
