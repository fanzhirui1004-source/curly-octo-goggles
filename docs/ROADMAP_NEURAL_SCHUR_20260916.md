# 完整 Schur 神经算子：路线图

日期 2026-09-16。本文合并三份来源：本轮实验讨论、外部审计意见、以及外部给出的执行 prompt。
所有数字均为本仓库实测，来源标在旁边。

---

## 一、我们在做什么

晶格由 TPMS 单胞拼成。拼装时只需要每个单胞的**边界响应**：边界被推成什么形状，边界推回多大的力。
内部怎么变形不需要知道。这个关系就是 Schur 补 `S`，它是精确的，不是近似。

问题是算 `S` 很贵。一个生产单胞 231,192 自由度，PARDISO 在 64 核上要 31.85 秒
（`docs/GP_TEACHER_TREE_COST_20260916.md`）。拓扑优化里几何一直变，扛不住。

目标：**网络输入几何，直接给出完整接口上的 `u ↦ S u`，跳过内部求解。**

不是把 `S` 变稀疏，不是端口降阶，不是只拟合少数载荷，也不是在推理时重跑有限元消元。

## 二、为什么换形式

旧后端是 `Â = Wᵀ(I + MMᵀ)⁻¹W`，`W = L·pi(Bᵀ)`，`L` 带状，`M` 稠密秩 1500。

`(I + MMᵀ)⁻¹` 的特征值全在 `(0, 1]`，所以在教师白化坐标下

```
H = H₀ − P,   H₀ = R*⁻ᵀWᵀW R*⁻¹,   P ⪰ 0,   rank(P) ≤ k = 1500
```

**低秩项只能变软，不能变硬。** 由此得两个精确的必要条件：`λ_min(H₀) ≥ 1 − τ`，以及
`#{λ(H₀) > 1 + τ} ≤ k`。违反任一条即证明**没有任何 `M`** 能让这个 `L` 过门。

实测（`superelement/factor_fit/reachability.py`，一次 d×d 特征分解，22 秒）：

| 状态 | `λ_min(H₀)` | 超 1.1 个数 | 超 1.03 个数 | 结论 |
|---|---:|---:|---:|---|
| 初始未训练 | 0.0172 | 1809 | 1940 | 两侧都违反 |
| R7 第 1000 步 | 0.0695 | 1540 | 2637 | 两侧都违反 |
| R8 第 1000 步（规范钉） | 0.1301 | 2095 | 3050 | 两侧都违反 |

绑住的是**软侧**：工作门要 `λ_min(H₀) ≥ 0.9`，实测 0.0695，差 13 倍；R7 时秩侧只差 40
（1540 对 1500）。初始有 10629 个方向低于 0.9，R7 第 1000 步还有 4536 个，低秩项一个都帮不上。

`λ_min(H₀)` 随训练从 0.0172 升到 0.1301，说明 `L` 在学对的东西，只是远未够。
**这不证明这一族没有可行的 `L`**，只证明已测的三个 `L` 都不行。

独立核对补充一点：秩瓶颈论证**不是**旧后端失败的原因（`L` 满秩），它针对的是全局隐变量瓶颈类设计。
旧后端的病因就是上面的单向性。

## 三、新形式

```
Â_θ = T_θᵀ D_θ T_θ,      Ŝ_θ = B_θᵀ T_θᵀ D_θ T_θ B_θ
```

`T_θ` 是网络生成的可快速作用的可逆线性变换，`D_θ` 是小块正定块对角矩阵。
几何到系数可以非线性，给定几何后位移路径严格线性。

构造上直接保证：对称、半正定、恰好六个刚体零模态、**且 `D` 双向自由，能变硬也能变软**。
最后这条正是旧后端缺的，而且是实测出来的，不是偏好。

推理路径 `u → B → T → D → Tᵀ → Bᵀ → r`，不求内部平衡，不对新几何做大矩阵分解，不展开 `Ŝ`。

### 必须先解决的设计张力

独立核对发现了一处 GPT 的 prompt 和我都没注意的问题。

`log det Â = 2 log|det T| + log det D` **只在 `T` 作用于 d 维商空间时成立**。此时两个 `B` 相消，
`Â = TᵀDT` 恒等。

但「`T` 由局部小块组成」这句话是**节点索引意义上的**，也就是说 `T` 天然活在 q 维 trace 空间里。
此时上式**不成立**，缺一项 `log det(Nᵀ M⁻¹ N)`，估计 18–93 nats，会让 `D` 错到目标门预算的 10–100 倍。

所以 E0 之前必须二选一并写进实验卡：

| 选项 | `T` 作用空间 | 局部性怎么定义 | log-det |
|---|---|---|---|
| A | d 维商空间 | 需要在商坐标上定义邻接，而商坐标不能仅凭数组索引解释成物理邻接 | 可加，便宜 |
| B | q 维 trace 空间 | 节点邻接，自然 | 需保留刚体修正项，成本 6 次求解加一个 6×6 |

已有实现里正确的形式在 `superelement/v1_superelement.py:449` 和 `superelement/spectrum_eval.py:25-28`，
选 B 的话直接沿用，不要自己重写成便宜版本。

## 四、验收标准（有一处重要修正）

```
H = R*⁻ᵀ Â R*⁻¹,    ε_op = ‖H − I‖₂ = max_i |μ_i − 1|
工作门：所有 μ_i ∈ [0.9, 1.1]
目标门：所有 μ_i ∈ [0.97, 1.03]  且  D/d < 1e-4
```

**修正：头条数字应当是 `ε_op`，`D/d` 降级为训练诊断。** 三个理由：

1. ±3% 目标门**恰好就是** Loewner 条件 `ε = 0.03`，也就是组合性界要用的那个 ε。它是可交付的证书。
2. `D/d` 对单个坏方向极不敏感：一个 `μ = 86` 的方向只贡献 `6.3e-3` 的 `D/d`；一个 `μ = 3.5` 的方向
   整个装进 `1e-4` 预算里还有富余。
3. 两个判据互相蕴含不了。真正蕴含 ±3% 的阈值是 `min{f(0.97), f(1.03)}/d = 3.449e-8`，
   比门里写的 `1e-4` 严 **2899 倍**（`f(t) = t − log t − 1`，本仓库复算）。

组合性界 `(1−ε)K ⪯ K̂ ⪯ (1+ε)K` 只在 `ε < 1` 时非平凡，而 ε 是**全部 12792 个方向的上确界**，
不是分位数也不是计数。旧后端当前 `μ ∈ [0.0695, 1.2045]`，`ε = 0.93`，下游每一条界都是空的。

另外，商空间到完整 trace 的传递要求**部署的算子字面上是 `BᵀÂB`**，不能是辅助矩阵 `K₀`，因为规范自由度
允许 `K₀` 与之相差很远。这是部署约束，要写进契约。

### 检查点四态

| 状态 | 含义 |
|---|---|
| `NUMERIC_PASS` | 经独立全方向数值审计，满足相应门槛 |
| `FAIL_WITNESS` | 找到明确超门的方向 |
| `UNVERIFIED` | 现有估计未发现失败，但不足以证明全方向通过 |
| `INVALID_NUMERICS` | 数值或审计一致性失败，不能据此判断拟合质量 |

单侧谱估计落在门内不能记通过。平均 loss 小不能记通过。
所有独立审计必须重新加载同一冻结检查点并重建全部缓存（本仓库已因混用更新前后参数产生过失效审计）。

## 六、已撤回的结论

不要在这些上面建任何东西。完整清单见 `BRIEFING §11`，这里列影响新工作的。

1. **「训练损失失真 2.47 倍」** — 是我的审计脚本漏传 `solve_tol`，触发了「算不动就悄悄换目标」的分支；
   同时 R7 用 `1e30` 当哨兵但残差到了 `1.998e+30`，1199 步里有 187 步（15.6%）真的切换了目标。
   **所以「历史训练发生过目标切换」要保留，「公式本身算不准」要撤回。** R7 不能当干净对照。
2. **「学生在收敛到物理正确的刚体奇异算子」** — 六个零模态来自恢复规则 `Ŝ = BᵀÂB`，不来自 `K₀`。
3. **「六个特征值各缩小 3.2e-40」** — 行列式给乘积，不给逐个特征值。
4. **「钉住规范不会偏置拟合」** — 只在模型能独立实现任意刚体块时成立，带状 `L` 做不到。
5. **「平均再降四个数量级也不保证过门」** — 错。`D/d < 3.449e-8` 即蕴含 ±3%，从 `2.11e-5` 需降 612 倍。
6. **`(B∘B)c` 是精确的** — 它只用 `C = BᵀA⁻¹B` 的对角，是对角近似，1.13–1.21 就是它的误差。
7. **`O(q²)` 交付不可避免** — 只对逐元素写出成立，不对完整接口上的隐式算子成立。
8. **「纯局部已被证否」** — 截断教师因子只给最优局部误差的**上界**，不给下界。
9. **闭式最优 `D` 可以直接用在旧后端** — 旧后端的 `(I+MMᵀ)⁻¹` 不是块对角，公式不适用。
10. **31.85 秒是单独否决线** — 对等比较两边都要含装配后求解。

## 七、工作路线

每接回一个未知部分，保留上一阶段作对照。一次失败只缩小调查范围，不判定唯一根因。

### E0：先证明实现和尺子可靠

**进入条件**：第三节的设计张力（选项 A 或 B）已决定并写进实验卡。

| 子项 | 内容 | 通过标准 |
|---|---|---|
| E0-A | 用合法参数造 `A_syn = T*ᵀD*T*`，小规模可显式展开。核对线性叠加、转置作用、双线性对称、能量梯度与反力一致、刚体恢复、结构化 log-det 与直接 log-det 一致、参数方向有限差分梯度 | FP64 下全部在预登记容差内 |
| E0-B | 同一合成目标，换初始化与种子重新学回。**不得**用目标参数初始化学生 | 只比最终算子。失败优先查实现、参数化、精度、优化，**不得**归因于真实 Schur 难 |
| E0-C | 植入 `H = I + αvvᵀ`，**α 要覆盖实测量级**：我们的坏方向偏硬到 `μ = 275/142/371`，不只是 `+0.5` | 评价器必须报出该方向，不因维数稀释而判通过 |
| E0-D | 实际接口规模下的构造、一次作用、反向、缓存存储冒烟测试 | 只测成本，不冒充物理精度验证 |
| E0-E | **可达性诊断移植到新后端**：给定 `T`，`C = TA⁻¹Tᵀ`，块对角 `D` 的 oracle 底为 `D* = Σ_b logdet C_bb − logdet C` | 训练前就能算出「这个 `T` 和这个分块最好能到哪」 |

E0-E 是独立核对给出的，价值很高：**它让带宽半径和块大小可以在训练之前对着目标门扫参**，
而不是训练完才发现结构不够。按块三角求解，不显式构造 `A⁻¹`。

**E0 不通过则停止**，不进入真实几何。

### E1：真实几何自由拟合

不接几何编码器，不接共享解码器。每个几何直接优化后端允许的全部系数。

样本：0328 作历史诊断案例，再从训练分区选至多三个标签可靠的代表，覆盖完整、普通裁切、薄或小支撑。
缺合格样本就报告，不自动启动新一轮教师生产。

| 子项 | 内容 | 说明 |
|---|---|---|
| E1-B | **先做**：固定 `T`，算块对角 `D` 的闭式最优 `D_b = (C_bb)⁻¹` 与 oracle 底 | 先问「这个 `T` 最好能到哪」再问「要不要多尺度」。我建议调换 prompt 里 A、B 的顺序，理由是 B 便宜且能在训练前证否 |
| E1-A | LOCAL 与 MULTISCALE 两种结构对照，相同能量块、损失、精度、尽量接近的参数与作用成本 | 单种子有限预算筛查，关键结论三个种子验证，不只报最好一次 |
| E1-C | 一次只放宽一项：固定块大小，只增多尺度轮数，新增层用恒等初始化使旧解仍可表示 | 每次扩容报告精度改善与增加的作用、存储成本 |

闭式最优 `D` 的限定：它最小化的是散度，**不保证**作用损失或最坏方向误差改善；
正式能量头若有额外约束，此结果是放宽对照；只替换部分块不得称为完整最优能量头。

**允许的结论**：在当前后端、预算和训练条件下，多尺度交换是否带来可重复的有效改善。
**不允许**推广成「所有局部网络都不成立」——截断教师因子只是一个坏候选，给的是上界。

### E2：共享解码器，不急着理解几何

进入条件：E1 数值可信，且真实案例上出现可重复改善。**不必等全部达到 ±3%，但必须保留未过门状态。**

从训练分区选约八个几何，每个给一个可学习编码 `z_g`：

```
(z_g, 编译器提供的块信息) → 共享解码器 → (T_g, D_g)
```

`z_g` 表示几何身份，**不压缩位移**，完整位移路径维数不变。与 E1 相比唯一主要变化是系数必须经共享解码器产生。

E1 好而 E2 明显变差时，调查共享解码器、编码容量、联合优化，**不能责怪尚未接入的几何编码器**。
不要回归各几何独立拟合的 `T, D` 系数——不同因子可对应同一算子，内部坐标不可比，监督仍施加于最终算子作用。

### E3：真实几何编码器

```
θ → 几何编码器 → z_θ → 同一个解码器 → (T_θ, D_θ)
```

第一版优先用现有几何参数加必要的编译器特征，不先堆复杂三维编码器。保留 E2 的自由编码版作对照。
训练几何上自由编码能拟合、真实几何编码不行，才重点查几何条件化路径。仍比较最终算子，不只比编码向量距离。

### E4：未见几何与归因

| 路径 | 用该几何标签 | 用途 |
|---|---|---|
| 几何编码器直接预测 | 否 | 真正的泛化成绩 |
| 冻结解码器，只优化新编码 | 是 | 解码器是否仍能表达更好的结果 |
| 同后端逐几何自由系数拟合 | 是 | 进一步诊断共享参数化与后端限制 |

补学编码只计入离线诊断，不计入零样本成绩。开发诊断集与最终测试集严格区分。

## 八、归因表

| 观察 | 优先调查 |
|---|---|
| 合成目标也学不回 | 实现、精度、参数化、优化 |
| 合成目标可以，真实自由拟合不行 | 后端与真实算子的匹配及优化难度 |
| 自由系数可以，共享编码不行 | 共享解码器、编码容量、联合优化 |
| 自由编码可以，真实几何输入不行 | 几何条件化路径 |
| 未见几何差，补学编码后好 | 几何到编码的泛化 |
| 局部审计好，装配差 | 接口映射、审计覆盖、整体求解与误差累计 |
| 精度好，总成本无优势 | 参数生成、作用、缓存或整体迭代成本 |

均为优先方向，不是一次失败就能下的唯一根因判决。

## 九、预算、探针与成本口径

**探针**：训练时持续更新白化随机探针，验证用独立种子与独立探针，另保留局部扰动、细尺度交替、
跨区域相对运动等诊断探针。被选入训练的最坏方向，后续必须用其他独立方向检验。

**预算**：每组实验启动前登记最大步数、允许重启次数、检查点、精度与资源上限。
不根据中途结果偷偷延长到「看起来成功」。NaN、Inf、结构测试失败或审计不一致时保存现场并停止；
单纯未过精度门标为**预算内未通过**，不自动判成表达不足。

**成本分列**：`T_compile`、`T_parameter_generation`、`T_apply`、`T_training`、`T_audit`。
同时报共享网络参数量、每几何缓存、峰值显存与磁盘。GPU 计时同步，冷启动与缓存后分开。
训练期教师 IO 与三角求解不能藏进网络成本，也不能混进无教师推理时间。

在线对等比较：

```
T_NN      = T_setup^NN      + T_solve^NN
T_teacher = T_condense      + T_solve^teacher
```

## 十、开放问题

1. 第三节的设计张力未决：`T` 放在 d 维商空间还是 q 维 trace 空间。这决定局部性的定义和 log-det 的成本，
   必须在 E0 之前定。
2. 旧后端的 `L` 能否把 `λ_min(H₀)` 从 0.1301 抬到 0.9，未知。这个标量每检查点 22 秒，
   应当在任何后续旧后端运行中作为主进度指标跟踪。
3. 极端模态项从未打开过。它是否真的在惩罚 `H` 的两侧极端（而不是 `K₀` 的原始特征值），
   梯度是否回传到算子参数，需要在 E0 中单独校准，不能因为「代码里有这个开关」就当它可用。
4. 恒等式目标的**梯度**准确性未核对，只核对了目标值。最小补证是在少数冻结检查点上用直接目标做方向有限差分。
5. 消元树的分层成本只有符号模型，没有逐层实测耗时，且用的是几何二分而非高质量排序。
6. 教师侧 `BRIEFING §3` 中标为「未确立」的项仍然开放，特别是完整 trace 谱与独立参考的对比。
