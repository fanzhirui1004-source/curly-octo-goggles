## 1. 双侧全谱（`FULLSPEC_DIRECT_01/`，进行中）

做法与冻结的全谱协议相同：G[:,j] = R^-T B S B^T R^-1 e_j，所有 d 个物理方向都保留，对称化后算全部特征值，
D/d = mean(μ − 1 − ln μ)。区别只在 S 用 cuDSS 精确作用（单元是多面体积分，有效分辨率 8）。

校验：中度 train13 用这条路径得到 [0.99923, 1.0064]、D/d 1.47e-7，与之前独立的 PARDISO 精确凝聚结果
[0.99923, 1.0064]、1.5e-7 一致。

已完成 7 个第二批样本（其余在跑）：全部通过目标门，最低 μ 0.99630，最高 1.00791，D/d 最大 2.4e-7。

## 3. 设计灵敏度（`SENS_01/`，进行中）

沿用 2026-09-19/20 的 τ 门协议：8 个角点同乘精确有理数 (1+ε)，ε ∈ {±1e-4, ±1e-3}。
- 教师侧：私有面板上重算 G 阶段 → 冻结代码重建 P、GP → 精确单元组装 A/C/D。
  只有 P、GP、刚体子空间都与基准完全相同的扰动才算可比（否则是单元出生/死亡，算子不在同一基上）。
- 几何侧：同一 P、GP，只把多面体积分的 τ 换成 τ(1+ε)。
- 观测量（两侧同一段代码）：非刚体子空间上的 log det、trace(S^-1)、最软/最硬特征值、8 个固定载荷的柔度。
- 比较对数斜率 d ln(obs)/dε，门槛 3%。

样本 0008、0020、0013。已知：0008 在 ε = −1e-3 时少了一个活动单元（边界维数 14304 → 14292），这一步不可比，只用 ±1e-4。

## 4. 旧网络 E1 在困难方向上是否也出错（`ATTR_01/`）

中度 train13（E1 的训练样本之一），E1 = M_q 标签、6 万步。坐标系与我们的见证完全一致（Householder 帧差 1e-16）。

| 方向 | E1 柔度比（教师 = 1） | E1 刚度比 |
|---|---|---|
| 32 个随机方向 | 1.68 – 1.81（中位 1.74，整体偏软） | 15.8 – 985（中位 196） |
| 求解器困难方向（原骨架 64 层，μ = 12.6 的方向） | **0.377（偏硬 2.65 倍）** | 66.2 |
| 几何单元误差最大的方向 | 3.20 | 1.6e4 |
| E1 自己的两个极端特征方向 | 65.1 / 3.2e-7 | 0.0154 / 3.1e6 |

- 困难方向对 E1 确实特殊：E1 在其他方向整体偏软，只有在这里偏硬，而且落在随机方向的范围之外。
- 但它不是 E1 最差的地方：E1 自己的极端特征方向与困难方向正交（余弦约 0），前 24 个边界坐标完全不重叠。
  E1 的误差范围跨 8 个数量级（μ 从 0.015 到 3.1e6），绝大部分不在强耦合节点对上。
- 所以强耦合节点对只能解释 E1 失败的一小部分。只有一个样本，而且是训练样本；E2 等全谱批次跑完后再算（内存需求大）。
