## V0：自由系数表示容量测试（0415）

最终形式：Ŝ = L_GGᵀ (I + MMᵀ)⁻¹ L_GG。L_GG 是面网格上半径 0.2 的带状上三角因子，对角用教师对角初始化；M 是 512 个稠密全局软化列；严格正定，无约束。损失是教师能量度量的相对误差，探针为白化均匀方向、粗空间光滑场、支撑加权细场，外加各向同性作用项，V0G 起加对偶项。

| 轮次 | 改动 | 白化均匀误差 | e_A | 平滑能量最大误差 | 平滑逆响应能量误差 | 结论 |
|---|---|---|---|---|---|---|
| V0A | 首版，稀疏内部耦合，支撑加权探针 | 未测 | 63.6% | 21% | 无 | 碎片节点偏刚 258 倍，损失几乎不激励它们 |
| V0B | 加白化探针，学习率 3e-3 | 崩溃 | 无 | 无 | 无 | 稠密内部因子三角回代几何级放大 |
| V0C | 行对角占优内部因子 | 1.62 | 23.2% | 39% | 9.6 | 首次突破 38.8% 对角线；内部耦合与低秩头被退化方向压到零 |
| V0D | 消掉内部因子，幂迭代收缩约束 | 0.091 | 23.1% | 22% | 15.3 | 约束不严，Ŝ 失去正定，逆响应发散 |
| V0E | 精确正定 Woodbury 形式，稀疏耦合 | 停止 | 无 | 无 | 无 | 每步 3.8 秒，稀疏 Gram 反向太慢 |
| V0F | 同形式，稠密 512 列，20000 步 | 0.011% | 0.137% | 0.22% | 0.45 | 正向指标全部过关；一个碎片模态被软化到零，逆响应失真 |
| V0G | 从 V0F 续训 4000 步，加对偶项 | 0.12% | 0.137% | 0.21% | 0.043 | 对偶误差 24 → 0.0034；力控位移能量误差 0.17 |

V0G 终点的力控指标：光滑方向逆响应能量误差 4.3%，局部方向 7.9%，支撑加权光滑力位移 16.6%，柔度最大误差 6.0%，高斯随机力位移 37.6%。趋势单调下降，学习率已衰减到 3e-5。

判断：表示容量已证明充分，正向指标超过门槛两个数量级。剩余误差集中在小切碎片节点的逆响应，是优化时间问题，也是 V1 网络必须逐节点解决的问题。

关键教训：

1. 能量损失对"过软"有界，对"过刚"无界，单独使用会把个别模态软化到零。对偶项 ‖R*(BŜBᵀ)⁻¹R*ᵀξ − ξ‖² 用模型的精确受限逆，把过软惩罚变成无界，是必需的。
2. Schur 补只依赖 M = L_GI C_II⁻¹，内部因子不应是独立参数。(I + MMᵀ)⁻¹ 形式把软化写成闭式且严格正定。
3. 任何约束都不能靠幂迭代近似执行，优化器会把所有方向同时推到边界。
4. 大量共享参数的稠密三角因子在 Adam 下会失去对角占优，三角回代放大失控。

## V1：几何网络版本（多标签）

网络：六个面各一张 65×65 图，通道为解析场在深度 0、1、2、4 的切片、节点掩码、支撑度量、坐标和面编码，共 54 通道；四个空洞卷积残差块，感受野约半径 0.23；节点特征做 LayerNorm 后接三个头：对角头输出有界的对数修正，配对头在近场节点对上输出有界的 3×3 块，模态头每个自由度输出 512 列。参数 58.8 万。

标签：训练划分里选 32 张 q ≤ 26000 的 FULL 标签，教师因子用项目自带的 dense_reference 生成。项目代码禁止打开正式验证集，留出集取训练划分中未用的 6 张，另加 0401。

冒烟测试发现的两个问题及修正：

- 共享权重的相干更新让网络在 40 步内把整个算子软化到零，能量损失停在 1。修正：特征归一化、头输出用 tanh 限幅、能量损失权重在前 3000 步线性爬升、作用项从头保持。
- 对偶项在 L 条件恶化时爆到 1e64。修正：对偶误差用 tanh 软饱和到 1e4，梯度非有限时跳过该步。

修正后 400 步冒烟：e_A 59% → 46%，留出标签 45%，无发散。正式运行 V1A：26 张训练标签轮转，20000 步，每 3000 步在 3 张训练和 3 张留出标签上做完整评价。
