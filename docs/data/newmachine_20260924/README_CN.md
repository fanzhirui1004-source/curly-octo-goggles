2. 3 个样本（0013 切割、0021 切割、0013 FULL）× 5 个立方群元素（交换 x/y、x 镜像、绕 z 转 90°、中心反演、一般元素），几何按生产代码 `families.rotate_geometry` 的公式旋转后重走流水线：
   - 活动单元、节点、盒面节点、GP 面：15 例全部恰好等于原集合在固定网格上的置换像（整数逐个比较）。
   - 每个几何只有一种单元节点顺序：单元刚度 = 125 个单元矩 × 同一个固定模板。
   - 盒面算子 T_旋转 与 Π T Πᵀ：相对 Frobenius 差 1e-15（轴交换）、1e-11（反演）、5e-8 到 1e-7（镜像、90° 转动、一般元素）；
     随机方向和 32 个最软方向（切割胞）上的相对能量差最大 9e-7。
   - 残差来自多面体积分中子立方体切四面体的朝向，比积分误差（约 1e-4）小三个数量级，比 3% 的门小五个数量级。
3. 切割带（被平面穿过的活动单元）：0013 有 532 个单元，0021 有 394 个，FULL 为 0；其节点都是固定网格节点。

结论：在当前流水线下，几何变化只改变固定网格上的掩码和单元系数，坐标系不变；立方群增广与流水线相容（到 1e-7）。
