## 2. 0d 收敛的最坏方向（进行中）
- 原算法问题：`a0_eval.worst()` / `trainlib.Geo.adversarial()` 是不带位移的块幂迭代，只保留最后一块。S̃⁺Ŝ = I + O(ε)，每步收敛因子接近 1，停止判据又很快满足。full16 中 768 条 V0/V0R 记录里 268 条的"最坏"低于 64 个采样方向的最大值，190 条低于其均值。P1 训练日志里的 adversarial 方向（`ritz_top` ≈ 1.0003）也来自同一迭代。
- 新求解器 `a0_worst.py`：阶段 A（Neumann 因子）生成块 Krylov 子空间，用欧氏正交基（S̃-正交递推会漂移：每次归一化把求解舍入放大约 1/ε）；阶段 B（内部因子）用精确 S̃V 做 Rayleigh–Ritz，Ritz 值不论子空间好坏都是下界。收敛检查：前半个基的 Ritz 值。合成矩阵测试（含 1e-7 相对噪声）：bulk 2.0e-3 → 1.998e-3，孤立模 44.5% → 44.50%，几个 1–2% 的模 → 2.000%，噪声地板约 ±2e-5。
- 另算"只在 box 面加载"的最坏值（切割面在格架里自由、无载荷）：载荷限制在 box 端口并在其上自平衡。这只是下界，收敛比全空间慢。
- 2012_d0_v2（恒等，冒烟测试）：μ−1 = 44.82%（前半个基同值，已收敛），前 3 个 44.8 / 42.2 / 40.5%；box 载荷最坏 ≥ 3.85%；min Ritz − 1 = 1.6e-6 ≥ 0。最坏方向：位移 99.99% 在切割带节点、97% 在弱支撑节点，约 12 个节点；产生它的载荷 100% 在切割带上；误差能量 80% 在弱节点上；一致面力方向库几乎不激发（span cos² 2e-4）。
