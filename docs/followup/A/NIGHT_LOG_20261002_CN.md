## 2. 0d 收敛的最坏方向（进行中）
- 原算法问题：`a0_eval.worst()` / `trainlib.Geo.adversarial()` 是不带位移的块幂迭代，只保留最后一块。S̃⁺Ŝ = I + O(ε)，每步收敛因子接近 1，停止判据又很快满足。full16 中 768 条 V0/V0R 记录里 268 条的"最坏"低于 64 个采样方向的最大值，190 条低于其均值。P1 训练日志里的 adversarial 方向（`ritz_top` ≈ 1.0003）也来自同一迭代。
- 新求解器 `a0_worst.py`：阶段 A（Neumann 因子）生成块 Krylov 子空间，用欧氏正交基（S̃-正交递推会漂移：每次归一化把求解舍入放大约 1/ε）；阶段 B（内部因子）用精确 S̃V 做 Rayleigh–Ritz，Ritz 值不论子空间好坏都是下界。收敛检查：前半个基的 Ritz 值。合成矩阵测试（含 1e-7 相对噪声）：bulk 2.0e-3 → 1.998e-3，孤立模 44.5% → 44.50%，几个 1–2% 的模 → 2.000%，噪声地板约 ±2e-5。
- 另算"只在 box 面加载"的最坏值（切割面在格架里自由、无载荷）：载荷限制在 box 端口并在其上自平衡。这只是下界，收敛比全空间慢。
- 2012_d0_v2（恒等，冒烟测试）：μ−1 = 44.82%（前半个基同值，已收敛），前 3 个 44.8 / 42.2 / 40.5%；box 载荷最坏 ≥ 3.85%；min Ritz − 1 = 1.6e-6 ≥ 0。最坏方向：位移 99.99% 在切割带节点、97% 在弱支撑节点，约 12 个节点；产生它的载荷 100% 在切割带上；误差能量 80% 在弱节点上；一致面力方向库几乎不激发（span cos² 2e-4）。

结论：
1. 学习型算子的格架误差不随格架尺寸增长，且由单胞误差控制：格架误差 ≤ 能量超额加权界，而后者是单胞量。
   - 拉伸 κ = 2 下，一致载荷误差随 n 略降（端面胞占比下降）。
   - c2w 比 c1 好约 4 倍：一致载荷 0.3–0.5%，任意载荷约 1%。
   - PCG 迭代数与精确算子相同（c2w）或多约 5–12%（c1）。
2. 即使对每个 J 重算均匀化张量（"均匀化能做到的最好"），在 2–4 胞的格架上仍有 −12% 到 −46% 的柔度误差：均匀化模型偏刚，误差约按 1/n 衰减。按此外推：
   - 降到 5% 约需 n ≈ 12–18 胞（恒等：n·误差 ≈ 0.62 压缩 / 0.88 剪切，三个 n 上几乎不变）；
   - 降到 1% 约需 n ≈ 60–90 胞。
   原因是自由表面胞与载荷 / 固支端面胞的边界层；这正是贴体点阵与夹层芯（芯厚只有几个胞）的工作区间。
3. 廉价映射（只转动 / 全推前）在 κ = 2 下误差 −77% 到 +190%，且不随 n 收敛到 0（误差趋向张量本身的偏差）。只转动的误差甚至可以变号，且随 n 增大：y×2 的 +62% → +120%。它们在定量设计中不可用。
4. 对方向 A 论文的含义：在 2:1 拉伸的几胞厚结构上，
   - V0R + 共转 Jacobi + 弱片修正 + 2 循环（c2w），不重训，给出 ≤ 0.5%（一致载荷）/ ≤ 1%（任意载荷）的格架柔度误差；
   - 同一问题上，重算均匀化误差 12–46%，廉价映射均匀化误差 26–190%。
   这是"为什么要做细尺度学习型算子而不是映射均匀化"的直接证据。

要点：
1. 映射胞的装配比 P1 的路径慢 4–6 倍，时间几乎全在映射矩上（`mapped_moments`，15–22 s）。在两条路线里它都是单胞成本的最大项，学习算子省不掉。
2. 单胞施加：精确算子比学习算子快 7–11 倍（16 列）。自动微分伴随与 P1 部署用的 FastNet 一样快，所以这不是实现问题。
3. 一次设计迭代、每个胞的粗估：假设约 300 次 PCG 迭代、每胞 3 列。
   - 精确：20 + 6 + 15 ≈ 41 s。
   - c1：20 + 2 + 36 ≈ 58 s。
   - c2w：约 76 s。

   也就是说，在 GPU 上、分解能常驻的规模，学习算子不比精确凝聚快。P1 的速度对比对象是 CPU PARDISO（整体直解与常规凝聚），也明确写了不与快速的细尺度解法比；这个结论在映射胞上同样成立，而且装配更慢，差距更小。
4. 学习算子的真实优势是显存：每胞常驻 2.7–3.1 GB，精确路线为 6.0–6.8 GB（fp32 分解）或 8.5–10 GB（fp64），约 2.2–3.2 倍。32 GB 的卡上：
   - 精确最多常驻 4 个胞；
   - 学习约 9 个胞。

   两条路线的常驻量都是 K̃ 占大头。若给映射胞实现精简存储（只存 45 组加权矩，约 0.4 GB，按需重算单元矩阵，相当于 P1 的 lean），学习路线可降到约 1 GB/胞，优势扩大到约 6 倍。
5. 两个部署前必须修的问题：
   - 自动微分伴随的瞬时峰值 15 GB/16 列，格架上不可用，需要给 V0R + 共转 + 片修正写显式伴随（在 FastNet 的 ext / ext_T 外面套转动与校正）；
   - 映射装配需要加速。

   装配加速对两条路线都有利。两个方向：
   - 仿射或分片近仿射胞用 P1 矩乘常值 A；
   - 平滑映射在单元内对 A 做低阶展开。注意，只有在单元内用与几何一致的 J 时，刚体核才精确。
6. 格架层面的共享：扭转、弯曲这类映射下，同一转动类的胞只需一个算子（`lat_global.py`），对两条路线同样有效，不改变两者的比较。

对论文定位的含义：方向 A 不应以"比精确凝聚快"为主张。可以成立的主张是：
- 映射胞上保结构、误差可控、不需要重训的算子（§3、§7）；
- 与映射均匀化的决定性比较（§8、§9）：同样细尺度的成本下，均匀化有 12–46% 的格架误差；
- 显存可扩展（第 4 点），并如实报告计时。

## 11. ② 非仿射格架：扭转梁与弯曲夹层板（10-05，`lat_global.py`，`A0/runs/ldg0–2`，结果在 `docs/followup/A/ldg/`）
- 新功能（默认关）：`mapped_cell.make_map` 的 kind `global`，即全局映射 + 胞偏移，全局映射有 affine / twist / bend / bezier 四种。相邻胞在共享面上用的是同一个映射，所以格架协调。CPU 自检：共享面点差为 0，单胞的 twist / bend 与全局版本完全一致。
- 转动类：两个胞的映射若只差一个刚体运动，就有 S_p = T_R S T_Rᵀ。精确算子如此；学习算子在 V0R + 共转 Jacobi 下对相似映射严格等变，而校正与片修正都由 K̃ 构造，所以同样成立。
  - 扭转梁：同一截面位置 (i, j) 的胞共用一个算子，2×2×N 的梁只需 4 个。
  - 弯曲板：同一层 k 的胞共用一个算子。

  每次运行都会单独构建一个非代表胞做核对。三次运行的结果：精确算子相对差 1–2e-14，c1 / c2w 为 6e-8（fp32 水平）。共用算子成立。
- 宏观均匀化：在映射后的网格上用 Q1 等参单元，m = 4、8 外推（自检：恒等与箱体解一致；刚体旋转协变 3e-14；仿射拉伸与箱体解一致；扭转梁上 (4, 8) 与 (8, 12) 的外推差约 0.1%）。三种张量：
  - 逐胞重算：胞中心 J 对应的仿射胞周期问题，再按转动类旋转；
  - 全推前：参考张量按高斯点处的 J 推前；
  - 只转动：参考张量按高斯点处 J 的极分解转动部分旋转。
- 胞：P1 均匀厚度周期胞 τ = 0.22（homogP_t02200，14400 个端口自由度）。载荷为端面的一致单位合力 x / y / z（端面是刚性映射的，面积因子为 1，参考面权重就是物理权重），另加 2 个随机载荷。
