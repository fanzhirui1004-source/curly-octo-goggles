# 方向 A 论文提纲（草案，10-05，供作者定位）

依据：NIGHT_LOG_20261002_CN.md §0–§12。本文件只整理证据和缺口，定位由作者决定。

## 0. 建议的定位（基于 §10 的成本数据）

**不主张**"比精确凝聚快"。在 GPU 上，分解能常驻的规模，单胞精确算子施加更快；映射胞装配（17–24 s）两条路线都要付。

**建议主张**（三条，均已有数据）：
1. **迁移不重训。** P1 的学习凝聚算子经共转拉回（V0R）加共转 Jacobi，对任意相似映射严格等变；对一般映射（扭转、弯曲、剪切、拉伸、自由曲面）保留全部结构性质，即 Ŝ ≥ S̃、对称半正定、刚体核。误差由校正循环数控制，每循环约降 5 倍，不需要重训。
2. **少胞数下映射均匀化不可靠。** 即使对每个 J 重算均匀化张量，几胞厚的贴体或拉伸结构仍有 12–56% 的柔度误差（约按 1/n 衰减）。廉价映射（只转动 / 全推前）在 κ = 2 下误差 26–190%，且不随 n 收敛。同样问题上，学习算子为 0.1–0.5%。
3. **显存可扩展、计时如实。** 无分解：每胞常驻 2.7–3.1 GB，精确路线为 6.0–6.8 GB；精简存储后可到约 1 GB。显式伴随的施加峰值 1.4–1.7 GB。转动类让扭转、弯曲结构只需少数几个算子。

题目方向（暂定）：*Transferring structure-preserving learned condensation to conformal TPMS lattices: co-rotational equivariance, correction budgets, and the failure of mapped homogenisation at few-cell scales*

## 3. 缺口（投稿前需要补的，按重要性）

1. **带切割面的贴体零件。** 自由曲面零件的边界是被曲面裁切的胞。现有切割胞来自 P1 的渐变族（τ 不均匀），与均匀 τ 的周期胞相邻时几何不协调。需要：
   - 均匀 τ 的切割体（小规模数据生产，P1 的 prep 管线），或
   - 一条整族渐变的格架。
2. **统计量。** 格架实验目前只用了一个胞（τ = 0.22）。至少再加 2 个厚度（如 0.32、0.42）和一个渐变族。
3. **更大的格架、矩阵无关路线。** 现在用稠密算子，只能做几十个胞。需要：
   - 映射胞的精简存储（只存 45 组加权矩，按需重算单元矩阵）；
   - 用 MappedFastOp 的矩阵无关 PCG；
   - 目标是 100+ 个胞，用来展示显存扩展性。
4. **按 κ 自适应选择循环数的规则**，在格架上验证。现有数据已经支持"κ ≤ 1.3 用 c1，否则用 c2w"，规则需要写成可复现的形式。
5. **（可选）装配加速。** 映射矩占单胞时间的大头。两种思路：
   - 分片近仿射胞直接用 P1 的矩乘常值 A；
   - 平滑映射在单元内对 A 做低阶展开。

   需注意，只有 A 与几何一致时刚体核才精确。这一项对两条路线都有利，不改变比较结论。
6. **（若定位包含设计）映射胞的厚度灵敏度**（dmoments / sens 目前未实现）。
