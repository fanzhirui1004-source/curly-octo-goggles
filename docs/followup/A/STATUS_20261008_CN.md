# 方向 A：现状总结与后续推进（2026-10-08）

## 1. 一句话结论

方向 A 的方法已经完整跑通，主要结论都有原始数据支撑。

P1 的学习凝聚算子不重训，就能迁移到等参映射 TPMS 胞上，靠的是三样东西：物理刚体分离、共转拉回（V0R）、共转 Jacobi。

- **结构性质**：Ŝ ≥ S̃、对称半正定、刚体核由构造保证。
- **数值上**：fp64 刚体分离修好了细长扭转梁上的界违例。恒等格架 τ = 0.32/0.42 上还有 fp32 时期留下的约 1e-5 量级的违例，要等统一重跑确认。
- **误差控制**：由校正循环数和弱节点片修正控制。第 2 个循环约降 5 倍，再往后收益递减。
- **与均匀化对比**：在 2–4 胞厚的结构上，学习算子 c2w 的一致载荷柔度误差为 0.015–0.5%（τ = 0.22 的 2³ 仿射块最大 0.82%）。逐胞重算的映射均匀化偏刚 7–51%。同一载荷分量上，前者小 35 倍以上，多数情形约两个数量级。

有三点限制：
- 在 GPU 上，学习算子不比精确凝聚快。
- 主表还没有统一到推荐配置。推荐配置是 c2w（2 循环 + cutweakbox 片，半径 3）+ fp64 刚体。统一重跑因服务器失联，停在 τ = 0.22 的弯曲板。
- 显存扩展性的大格架算例还没做，论文定位也还没定，后者需要你来定。

### 2.6 精度与稳健性修复

**fp64 刚体分离（rigid64）**
- **问题**：
  - 现象：扭转梁斜切的 c2w，在 fp32 刚体下 y 向误差为 +0.051%，界为 −0.051%，违反 Ŝ ≥ S̃。
  - 原因：细长梁侧向柔度约为轴向的 40 倍，每个胞的端口迹几乎都是刚体运动。大刚体分量的 fp32 舍入通过交叉项进入能量。
- **修复后**：改为 fp64 刚体，所有误差为负、所有界为正。
- **fp32 噪声有正有负**，不是单向偏差：
  - 扭转梁斜切上，c1 侧向误差从 −0.44% 变为 −0.65%；
  - 扭转梁上，修正量不超过 0.07 个百分点。
- **默认与生效条件**：自 cb44b25 起为默认，但只在 `--fast 1` 下生效。

**片半径 3**
- **问题来源**：随机载荷的残余误差来自片没有覆盖整个弱区。
- **单胞代理**：
  - 力驱动代理 q = S̃⁺f 与格架结果吻合（1.56% 对 1.42%）。
  - 力驱动下，误差能量的 99.06–99.99% 在弱节点及其 2 格以内。
  - 所有变体都开了 rigid64，所以这里的半径对比不受刚体精度混杂。
- **半径 2 → 3**：单胞误差降 3.9–5.5 倍，优于 c4w；片从 2.4–2.7 万自由度增到 4.6–5.5 万。
- **格架验证**（τ = 0.32、z×0.5，4³）：
  - 随机载荷 1.42% → 0.33%；
  - 一致载荷 0.19% → 0.18%；
  - PCG 迭代不变；
  - 界全部为正。
- **局限**：
  - 只在这一个格架上验证过。
  - 格架对比中，半径 3 开了 rigid64，半径 2 的基线没开，混入了刚体精度的变化。
  - 两次运行的精确柔度差 2.8e-12 到 2.1e-11，不是逐位相同。

**其它修复**：最坏方向求解器重写；白化阈值从 1e-12 改为 1e-9，并加有效性标记。

## 4. 后续推进思路

### 4.0 写作时要如实说明的边界

1. **速度**：在分解能常驻 GPU 的规模下，学习算子没有速度优势，可主张的只有显存，而且只在不同胞很多的结构上才有意义。仿射格架只有 1 个算子，扭转梁和弯曲板只有 2–4 个，精确凝聚在这些结构上同样很便宜。
2. **均匀化对比的范围**：
   - 比的是 2–4 胞厚、给定边界条件下的柔度。边界层误差本是预期的物理现象，均匀化本来也不是为 n = 2–4 设计的。
   - 「n ≈ 12–18 时误差降到 5%」是外推。
   - 切割零件没有做均匀化对比。
3. **只有一个网络检查点**（A3），没有种子方差。
4. **胞族与边界条件单一**：
   - 格架只用了 P1 的均匀厚度周期胞（homogP，τ = 0.22 / 0.32 / 0.42）及同族切割体，渐变族没做；
   - 边界条件都是一端固支、另一端面加载；
   - 16 个验证胞只用于单胞层面。
5. **切割面**：只做了 τ = 0.22、一个全局竖直平面（映射后成曲面）。切割胞仍是 P1 训练族里的平面切割，一般曲面裁切没有测过。
6. **κ 范围**：单胞预算只测到 κ ≤ 2（格架里局部最高 2.47），而叶片类目标的 κ 可达 3.5–4.7。
7. **格架规模**：最大 4³（τ = 0.42 时 77 万自由度）。
8. **最坏方向**：
   - 只有 1 循环 + 半径 2 + fp32 刚体的数据；
   - 只覆盖 4 个映射；
   - box 载荷最坏只是下界。
