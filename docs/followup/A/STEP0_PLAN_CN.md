# 方向 A 第 0 步：映射单胞上的零样本测试（方案与进展）

2026-10-01 起草。依据：`docs/followup/LIT_SURVEY_AB_20261001_CN.md` §2.4–2.5、`ROADMAP_20261001_CN.md`。

## 1. 要回答的问题

1. **是否需要以 J 为条件。** P1 训练好的网络（A3）不经任何再训练，直接用于映射后的单胞，精度能保持到什么程度？如果只靠精确算子校正就能把误差压住，"Jacobian 条件化"就没有必要，A 的论文主线改为"精确映射算子校正足以吸收映射"。
2. **单侧界与校正在分布外是否稳健。** 映射越强，误差是否单调、平滑地增长？Ŝ ≥ S̃ 是否始终成立？

## 2. 离散设定（已实现）

- **几何。** 水平集、背景网格、激活单元、ghost 面和端口全部沿用参考单胞，只有刚度变化。这是综述 §2.4 陷阱 2 建议的"参考坐标水平集"设定。
- **映射用 Q2 等参插值。** 节点物理坐标 x_a = Φ(X_a)，单元几何为 x_h(t) = Σ x_a N_a(t)。这样转动 W x_h 落在离散空间里，物理刚体模态是精确的零能模态（陷阱 1）。
- **单元刚度。** 写成 K_e[a i, b k] = ∫ ∂N_a/∂t_J · A_iJkL · ∂N_b/∂t_L dt，其中 A = det J · J⁻¹ C J⁻ᵀ。只变换导数指标，位移仍是笛卡尔物理分量。
  - 积分规则沿用 P1 积分器的正权规则：同样的子立方和 Kuhn 四面体切割，切割块上用 Gauss–Jacobi。
  - 全在材料内的子立方由解析式改为 3 点 Gauss，整单元全满时用 5 点 Gauss。这两种规则对 Q2 导数乘积精确，所以恒等映射下与 P1 的矩阵逐项相同。
  - 同一个求积和改写成 45 组加权矩（9×9 对称矩阵 A 的独立分量）乘固定模板，保持 P1 "矩 × 模板"的结构。权为正、det J > 0，因此每个 K_e ⪰ 0。
- **ghost penalty 在物理坐标下计算。** 用物理梯度、完整的等参 Hessian、映射后面的物理法向和面积元，以及 h_x = h·det(∂x/∂X)^{1/3}。刚体运动的物理梯度为常数、物理 Hessian 为零，所以罚项不作用于刚体运动。恒等映射下与 P1 模板相同；刚体转动和均匀缩放下的变换规律都精确。
- **刚体基。** Q 和 Qall 由物理节点坐标生成。

## 5. 实验设计

**单胞。** 先在 4 个胞上试跑，再扩到 16 个胞。16 个胞即 P 验证胞 fresh_val_2000–2015，与 G 胞零样本测试所用相同，便于对比。试跑的 4 个胞取完整胞和切割胞各 2 个。

**映射族（每个胞 24 个映射）。**

| 族 | 参数 | 作用 |
| --- | --- | --- |
| 恒等 | — | 流程回归：应当重现 P1 上 A3 的数值 |
| F0 刚体转动 | 30°，一般轴 | 合理性检查：V0R 应与恒等映射一致 |
| F1 仿射 | 沿 x 拉伸 0.5、2；剪切 0.15、0.3 | 胞内 J 为常数 |
| F2 扭转 | 每胞 2°、5°、10°、20°、30° | 主测试 |
| F3 弯曲 | R/L = 20、10、5、3 | |
| F4 渐变 | 尺寸比 1.1、1.25、1.5 | |
| F5 Bézier 随机扰动 | 幅度 0.025、0.05、0.1（胞长），2 个种子 | |

**变体（A3 权重不变；校正沿用 A3 的 tail(8)–Q1_17 粗修正–tail(8)，全部用 K̃）。**

- **V0**：网络在参考网格上运行；刚体部分用物理刚体模态精确分离。
- **V0R**：在 V0 的基础上加共转拉回。非刚体端口值先旋转到局部参考方向（R 为节点处 ∂x/∂X 的极分解因子），网络延拓后再转回。不需要训练，专门检验误差主要来自"转动"还是"度量畸变"。
- **V0ref**：沿用 P1 的参考坐标刚体分离，作为诊断，看不考虑映射直接部署会怎样。
- **Conly**：不用网络，只做刚体部分加校正，看校正单独能做到什么程度。

以上都是线性延拓，并按能量形式读出，因此 Ŝ ≥ S̃ 成立；评测中用最小能量超额检查这一点。

**方向库（单位精确能量，每类 64 个验证方向）。**
- force、macro、grf：载荷和位移场在物理端口位置上取值。
- force_c、face_c（P1 主指标所用的一致面力类）：面积元用映射后的物理面积（Nanson 公式），面力场在物理积分点上采样。

**指标。**
- 每类能量超额 e = uᵀK̃u − 1 的均值、p90、最大值和最小值（检查 ≥ 0）。
- 最坏方向 μ = λ_max(S̃⁻¹Ŝ)，V0 与 V0R 用 Geo.worst_ratio 求。
- 映射统计：min det J、max cond J。
- 物理刚体残差、Chebyshev 区间，以及计时和显存。

**第 0c 步（单胞结果出来后再定）。** 2×2×2 格架 hlat222 做整体扭转，看格架柔度误差和 PCG 迭代数。

## 6. 判据（沿用综述 §2.5，稍作收紧）

- (a) 所有测试中最小能量超额 ≥ −1e-10，否则是实现错误。
- (b) 恒等映射重现 P1 数值（force_c 均值约 0.07%）。
- (c) 误差随畸变单调、平滑增长。
- **决策：**
  - V0 或 V0R 在扭转 ≤ 10°/胞、弯曲 R/L ≥ 5 时，force_c 均值 ≤ 0.5%：不需要 J 条件化，A 的主线改为"共转拉回 + 精确算子校正"。
  - 否则（例如 5° 即超过 1%，且 V0R 也救不回来）：J 条件化成立，进入数据生成，届时考虑另租一台机器。
