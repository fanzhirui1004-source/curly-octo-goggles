# 后续工作推进路线（2026-10-01 起，按月计；时间为估计值）

依据：P1 现状（HANDOVER_20261001_CN.md）、文献调研（LIT_SURVEY_AB_20261001_CN.md）、此前的竞品筛查。原则：

1. **先占位，再做大。** 抢发风险高的方向先出一个短而扎实的结果，挂 arXiv 预印本，再扩成完整论文。
2. **P1 是所有后续工作的地基。** 投 CMAME 的同时挂 arXiv，后续每篇都引用它。Elsevier 允许投稿前公开预印本，具体以投稿时的期刊政策为准。
3. **每条工作线一个独立任务。** 各开一个会话、一个分支，有自己的接手文档。共享 P1 代码与数据，不互相改对方的文件。
4. **GPU 是瓶颈。** 目前只有一台 RTX 5090。多条线同时需要 GPU 时要排队，或者由作者决定加租。

## 4. 避免抢发的具体做法

1. **P1 一投稿就挂 arXiv。** 这能确立"NICE、单侧界、平衡校正、切割 TPMS 学习凝聚"的优先权。后面所有工作都以它为母文献。
2. **高风险线（A、B）先出"最小可发表结果"。** 不追求一次完整：
   - A：零样本扭转测试，加上映射 CutFEM 的正确性验证（刚体模态、λ_min ≥ 1），就是一篇 4–6 页的短文或预印本，内容就是"精确算子校正让学习凝聚在样条映射下仍然安全"。
   - B：命题 1–3，加上实测的最坏 ε，再加一个 3D 点阵 BDDC 算例，就足够一篇预印本。
3. **数据集（DS）早发。** 公开后，别人做切割 TPMS 的学习方法都会用并引用它，等于给后来者设了门槛。数据量很大时，可以先放一个子集，加评测协议和基线。
4. **每月盯竞品。** 一旦发现 Antolin 组的 3D 神经网络版，或郭旭组的 Jacobian 条件化 PIML，立即评估是否要把 A 或 B 的预印本提前。
5. **不要为了"多发"拆薄 P1。** 每篇都要有新问题、新数据、新结论，引用时写清楚复用了哪些内容。
