4. 框架结构带来的独有能力

前提：下面的"别人难做到"都是从框架结构推出来的。写进论文之前，每一条都要针对性地筛查文献，并写清楚"在什么条件下别人做不到"。
#能力来自哪个结构特点为什么别人难做
1在切割面上施加真实边界条件：支撑、载荷、接触；格栅与实体件在斜切边界上粘接保留完整切割带均匀化只能另加罚约束，本例中低估 27%；缩减边界方法的保留坐标里没有切割带；降基法依赖固定离散。证据最强，P1 的切割板已是雏形。
2不做分解就得到壁面级局部场：可做应力约束和局部屈曲指标内部延拓本身就是场均匀化给不出壁面应力；Jiang H. 恢复内部场需要分解；PIML 有场，但边界 DOF 太少，应力约低估 5.3 倍。风险：局部量误差不受能量误差控制，必须单独验证。
3精度在使用中可调：优化早期用小校正预算，收敛时加大固定校正加单侧界其他学习模型训练完精度就固定了。如果再配一个可计算的上界（余能或平衡残差），就有双侧界，可以做有认证的约束满足。
4频率的 Rayleigh–Ritz 上界：M̂ = FᵀMF 与 Ŝ = FᵀKF 用同一个 F延拓是同一个线性映射这是经典组件模态综合的性质；带变分界的学习子结构动力学很少见，需核实文献。
5有限尺寸效应与非经典耦合（拉扭）全分辨率组装，不依赖尺度分离Cauchy 均匀化给不出尺寸依赖，需要微极或应变梯度理论。
6对零件边界形状的灵敏度：同时优化外形和格栅网络以离散几何为条件难点是离散模型切换（3.3 节），放到长期。

7. 冲 NC 的路线

判断标准。NC 不会因为"方法更快更准"收稿。它要的是"有了这个方法，才看到、做成了以前做不到的事"，而且最好有实验。所以衍生工作的目标不是"更好的 NICE"，而是用 NICE 的三项独特能力去解决公认解决不了的问题：
  • 在没有尺度分离的地方给出精确级的可组装算子；
  • 给出局部场和局部灵敏度；
  • 有单侧界，且部署时可改进。
方向问题与展示差距评估
1. 局部量驱动的有限尺寸格栅设计（最推荐）均匀化在边界、切口、支承处给不出局部应力，梯度格栅设计基本只能优化柔度；但真实零件坏在局部，比如应力集中、疲劳、局部屈曲。展示：一个真实外形的零件（带孔或曲面边界的支架、植入物），上千个胞；均匀化设计和 NICE 设计都打印出来做破坏试验。K_PP 多层粗解（上千胞）；应力/强度目标及其灵敏度（场已有，主要是推导和实现）；打印与力学测试条件柔度设计我们只比均匀化好 2.4%，这对 NC 不够；应力类目标的差距应该大得多，要先用数值验证。估计 4–6 个月。
2. 有限尺寸超材料的振动设计声学和弹性超材料几乎都用 Bloch 周期分析，默认结构无限大；有限器件的边界模态和局部共振，周期分析给不出。展示：有限尺寸、带边界的 TPMS 板，指定频带内无模态，或把振动局域到指定区域，再打印并用激光测振验证。质量阵凝聚；特征值问题的组装求解；测振实验超材料是 NC 高频题材；"有保证的上界 + 有限尺寸设计 + 实测"组合较新。可作为同一套基础设施的第二篇。
3. 带误差保证的 ML 力学替代模型ML 替代模型最大的信任问题，是不知道什么时候错、错多少。如果能用平衡通量或对偶构造补上可计算的上界，就是"可认证精度的学习型结构算子"。可计算的上界（数学难度最高）更可能成为方向 1 或 2 的"信任"卖点，不宜独立成一篇 NC。

7.1 NC 前置条件（与 P2/P3 共用）

  1. K_PP 多层粗解或迭代粗解。替换 GPU 上的直接分解，目标上千胞。
  2. 第二胞族。gyroid 已有零样本和微调结果，需做成正式结果；或者用 B 样条拉扭胞充当第二族。
  3. 实验。打印对照件（NICE 设计对均匀化设计），做拉压或破坏试验，最好有 DIC；动力学方向需要激光测振。
  4. 质量和几何刚度凝聚。M̂ = FᵀMF、K̂_G = FᵀK_GF，动力学和屈曲共用。
  5. 后验误差估计。大规模时做不了精确核对，必须用它证明精度。

7.2 叙事

主线是"均匀化在边界失效，全分辨率在零件尺度算不动，NICE 让边界解析的设计变得可行，而且实物验证了它"。加速比在这个叙事里不重要。重要的是内存和成本的增长方式：直接法超线性，NICE 线性，再加上局部场和灵敏度。

8. 已有前期结果（可直接接上的）

结果内容对后续的意义
映射单胞第 0 步（16 胞 × 24 种映射，384 对全部成功）
  • Ŝ ⪰ S 与对称半正定在所有映射下都成立，最小能量误差 +3.1×10⁻⁷。
  • 刚体基必须在物理坐标里分离：按参考坐标分离时，旋转 30° 后刚体延拓能量达 0.14。
  • 共转拉回是必需的：整胞转 30° 时误差从 3.72% 降到 0.074%；扭转 10°/胞为 0.089%，弯曲 R/L = 5 为 0.097%，扭转 30° 为 0.27%。

10. 原则

  1. 每篇都有自己独立的招牌，不能只是同一方法换个算例或换个物理场。把 P1 拆薄，或者换个包装重复发表，会伤害整个系列的信誉。
  2. 共享前置排在前面（第 9 节），后面每篇都能复用。
  3. "别人做不到"先查文献：每个选定方向先做一轮针对性筛查，写清楚在什么条件下别人做不到。
  4. 不用 "Part I / Part II" 标题：各篇独立成文，用统一的术语和记号串起来。
  5. 开工前做算力预算：P2、P3 都需要较多 GPU 时间，P3 还要生成新数据。目前只有一台 RTX 5090，是否增租由作者决定。
  6. P1 先投、先挂 arXiv：后续每篇都引用它作方法基础。
  7. 数据和代码各发各的：引用前作时写清复用了什么、新做了什么。
  8. 实验统一规划：一个打印批次同时服务均匀化失效和板设计对照；NC 的零件级试件另外设计，避免与前面几篇重复。
  9. 对 PIML 的批评只放在答复信和内部讨论：正文不比数值，不把自己定位为 PIML 的升级，不写"first"。

12. 需要作者决定的事项

  1. 实验条件：能否打印金属或聚合物 TPMS 试件？能否做拉压、破坏试验（是否有 DIC）？能否做激光测振？这一项基本决定 NC 能不能走。
  2. B 样条拉扭单胞：做等效性质预测，还是结构设计？几何是薄壳、杆件还是实体？这决定它和 NICE 怎么接，以及能否作为第二胞族。
  3. 方向选择：两年内的 3–4 条主线（建议 P2 = B+D、P3 = C + 拉扭胞、NC 方向 1，再加一篇低投入并行篇）。
  4. 时间窗口：NC 方向 1 约需 4–6 个月（在前置完成之后），能否接受？
  5. 投稿：直接投 CMAME，还是先给 Nat. Comput. Sci. 发预投稿咨询？
  6. 算力与监控：是否增租 GPU？是否开启每月的竞品自动检索？
