# P1 之后的工作安排

后续工作的出发点是 P1 局限一节列出的几条限制，每一条对应一项要做的事。

## 一、先做的共享基础

这几项被后面几篇论文共用，先做。

1. **大规模求解。** 用多层或迭代粗求解替换保留系统的直接分解，使分析和设计能扩展到上千个胞元。
2. **后验误差估计。** 给出可计算的柔度与灵敏度误差估计，并据此按胞元自适应分配校正步数；同时查清最坏方向的来源。
3. **质量与几何刚度凝聚。** 用同一个延拓得到 \(F^TMF\) 和 \(F^TK_GF\)，为动力学和屈曲分析做准备。
4. **更多胞族的数据与训练。** 在 Schwarz-P 之外加入 gyroid 等胞族。

## 二、论文计划

- **P2：局部量驱动的点阵设计。** 以应力等局部量为目标或约束，配合后验误差估计与自适应校正，使局部量的误差可以估计和控制。
- **P3：跨胞族与几何泛化。** 多胞族联合训练、留出一族测试；映射或曲面边界的胞元；对称性由构造保证；可选：把粗网格校正并入网络。也可考虑拉扭耦合的 B 样条单胞。
- **备选：动力学与屈曲。** 利用 Rayleigh–Ritz 性质给出频率与临界载荷的上界，用于振动或屈曲相关的设计。

## 三、可并行的小工作

- 公开切割胞元精确凝聚数据集与评测协议；
- CutFEM 参考解中的方法细节（材料支撑判定、小切割稳定、矩导数灵敏度）；
- 均匀化在切割边界处失效的定量研究，可配合简单实测。

## 四、想请导师给意见的问题

1. P1 的投稿去向。
2. P2 先做局部量（应力）设计，还是先做动力学与屈曲。
3. 打印与力学测试的条件。
4. P3 是否纳入拉扭耦合单胞，以及具体形式。
