# 后续工作思路

## 一、基础推进

1. **大规模求解。** 用多层或迭代粗求解替换保留系统的直接分解，使分析和设计能扩展到上千个胞元。
2. **质量与几何刚度凝聚。** 用同一个延拓得到 \(F^TMF\) 和 \(F^TK_GF\)，为动力学和屈曲分析做准备。
3. **更多胞族的数据与训练。** 在 Schwarz-P 之外加入 gyroid 等胞族。

## 二、论文计划

- **P2：局部量驱动的点阵设计。** 以应力等局部量为目标或约束。
- **P3：跨胞族与几何泛化。** 多胞族联合训练、留出一族测试；映射或曲面边界的胞元；对称性由构造保证；可选：把粗网格校正并入网络。
- **拉扭耦合的 B 样条单胞。** 单独成篇。
- **动力学与屈曲。** 利用 Rayleigh–Ritz 性质给出频率与临界载荷的上界，用于振动或屈曲相关的设计。
