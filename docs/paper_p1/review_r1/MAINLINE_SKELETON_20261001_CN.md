## 二、主线定稿

### 1. 解决的问题

切割薄壁 TPMS 结构里的每个胞都需要一个可复用的模型：既要回传装配所需的力，也要回传局部设计所需的内部场。精确凝聚对每个新几何都要做一次内部分解，而设计迭代中每个胞的几何都在变，这个成本不可承受。已有的两类近似，要么改变胞间交换的位移模式（端口降维、少量边界坐标），要么没有力学结构、精度不受控（直接学习）。

支撑数字：每胞保留 1.7–2.6 万坐标；8 胞格架整体 Cholesky 一次设计迭代 868–1,042 s、因子 66–81 GiB；未校正的学习延拓能量误差 1–40%，装配后灵敏度误差 3–11%；边界限制到 8 次 Bernstein 时柔度误差 0.5–0.7%，但邻胞载荷下灵敏度误差仍 24–64%。

### 2. 用了什么（五个部件）

1. **离散参考模型**：Q2 CutFEM 加 ghost penalty，n = 32，Schwarz-P 带、8 个三线性角点厚度参数、一个平面切割。所有误差都相对这个离散模型的平衡态。
2. **完整保留空间**：箱面全部系数加切割带全部系数。近似只放在内部延拓。
3. **学习初值 Ê**：几何分支（非线性：单元矩、节点特征到系数）加位移分支（线性：单元和 ghost 面邻域相互作用，65/33/17/9 多层）；对 q 严格线性；刚体运动先分离、精确重构。
4. **固定校正 W**：Jacobi-Chebyshev 8 步、Q1(17³) Galerkin 粗解、再 8 步；每个几何一套系数，对所有 q 相同。
5. **能量形式读出加完整转置**：F = WÊ，Ŝ = FᵀKF，Ŝq = (KFq)_P + F_Iᵀ(KFq)_I。

外围：Ritz 型训练目标（对数能量比加灵敏度项），穿过校正训练；格架 PCG（K_PP 因子加宏顶点刚体粗空间）；场基灵敏度 s̃_c = −ûᵀK_{,c}û；MMA。

### 3. 证明了什么

**经典关系的重述（文中已声明）**：Ritz 恒等式 Ŝ − S = HᵀAH ⪰ 0；ε(q) = ‖r_I‖²_{A⁻¹} / qᵀSq；柔度误差等于重构误差能量（式 11）；Chebyshev 非扩张；Galerkin 投影的能量正交。

**本文针对学习型子结构推出的**：
- 参与率界（式 12）：0 ≤ (C − Ĉ)/C ≤ β/(1+β)，β = Σ w_m ε_m。整体误差被能量份额加权。
- 灵敏度误差（式 13）：s̃_c − s_c = −2dᵀK_{,c}u − dᵀK_{,c}d。线性项不消失，所以能量误差下降不保证灵敏度误差下降（J.9 有反例）。
- 完整代理导数（式 14）：场基估计不是代理目标的梯度，差一项与内部残差耦合的量。
- 校正排序（式 17）：谱包含加精确 Galerkin 推出 S ⪯ Ŝ_tg ⪯ Ŝ_0。保证的是排序，不是速率；是能量，不是灵敏度。
- 完整转置使算子误差为二阶（J.2）；没有它，返回的力不是所写能量的导数。
- ε = δ²κ：1% 的位移误差落在刚硬方向（κ 为 10² 到 10⁴）就变成 2–35% 的能量误差。这解释了为什么未校正网络"场看着不错、算子却差"。
- 残差功（式 18）：把近似误差和未收敛的求解分开。

### 4. 验证了什么（证据链）

单胞、校正、装配、格架、成本、设计六级，每级有精确参照：
1. 80 个验证几何：一致面力下能量误差 0.074%（最大几何均值 0.65%）；未校正 6.33%。NICE-post 0.0965%，训练环内校正再降 1.31 倍。
2. 固定权重的校正消融（表 3）：零初值 2,400–12,000 倍、图调和 7–290 倍于学习初值；M1 从 13.5% 到 0.186%。
3. 两胞装配：14 个开发配置柔度 ≤ 0.056%、灵敏度 ≤ 0.67%；18 个留出配置 0.27%、1.49%；未校正网络 11 个配置里 4 个灵敏度超 3%。表 4：柔度 0.00109% 对灵敏度 3.15%（Smoothing-trained，参与率 0.13%）。
4. 保留空间消融（6.8）：限制边界即使内部精确也留下灵敏度误差。
5. 全学习格架：柔度 ≤ 0.015%、灵敏度 ≤ 0.14%；参与率界与实测相差小于 0.4%。
6. 成本（表 5）：8 胞一次设计迭代 81–110 s、9.2 GiB，对整体 Cholesky 868–1,042 s、71–86 GiB（16 线程）。
7. 设计（表 6）：8 胞与精确凝聚孪生运行终设计相差 ≤ 0.0051，精确柔度相差 1.25×10⁻⁵；路径上梯度误差 ≤ 0.33%；板 B1、B2 精确核对代理误差 0.013–0.038%，梯度 0.22% 和 0.32%，符号全对；均匀化低估 27% 和 37%；110 胞 32.7M 自由度每步 43 min（仅计时）。

### 5. 创新点（按可辩护强度排序）

1. **把固定的多层平衡校正放进学习凝聚算子的能量形式里，并配上完整转置。** 结果：学习算子变成一个有变分结构的力学对象：对称、半正定、刚体核、≥ S、可装配、可微分，而且误差可以被校正只减不增地压低。现有学习子结构（PIML 系列、CNEE、Jiang 等）都没有这个结构；与混合神经求解器（校正用来加速一次全局求解）的本质区别也在这里。
2. **切割薄壁胞的完整保留空间（含切割带）上的几何条件化线性延拓。** 对 1.7–2.6 万个保留坐标工作。Guo 2026a 放弃的"全节点"路线在这里靠校正救回来（能量误差 0.07%，他们的位移误差 3.46%；误差定义不同，只作定位）。
3. **误差到响应的追踪和联合判据。** 参与率界、灵敏度的线性项、ε = δ²κ，说明为什么柔度准不等于灵敏度准，并给出设计使用必须同时核对两者的要求。
4. **一条到设计为止的验证链**：与精确凝聚的孪生优化对照，在学习子结构文献里少见。

次要（写进去但不当头条）：训练环内校正（1.31 倍）；保留表示消融；场基灵敏度与代理梯度的区分。

**不能主张的**：完整保留空间本身（静力凝聚就是）；能量形式的 PSD 和下界（任何可容许延拓都有）；Chebyshev 和 Galerkin 的性质；"柔度准不等于灵敏度准"这个现象本身（目标导向误差估计、近似重分析已有）；认证误差界（没有）；比整体迭代求解器快（没比）。

### 7. 一句话主线和三个问题

主线：**用"学习初值加固定平衡校正加能量形式读出"构造切割薄壁 TPMS 胞的近似凝聚算子，它保持精确凝聚的变分结构、误差可控可减，对整体分析和局部厚度设计都足够准确，而且每次设计迭代不需要内部分解。**

全文回答三个问题，每个问题一个主要部分：
- Q1 怎样构造一个有力学结构、可改进的学习凝聚算子？（方法）
- Q2 内部误差怎样分别进入整体柔度和局部灵敏度，判据应当是什么？（分析）
- Q3 它够准、够快、能做设计吗？（验证）

Codex 建议把 Q2 当全文中心。我的意见：Q1 是头条，Q2 是判据和动机，Q3 是证据。理由：Q2 的现象本身不新，立为核心会被按"分析是否新"来评；Q1 的结构（校正进能量形式加完整转置）才是别人没有的。

### 三条贡献（框架）

(i) 方法：在切割胞的完整保留空间上，把几何条件化的线性延拓、固定的几何专属多层校正和完整转置放进同一个凝聚能量构造；算子对称半正定、保持刚体核、以精确 Schur 补为下界，校正不增误差。
(ii) 分析：把内部误差追踪到装配柔度（参与率界）和局部厚度灵敏度（刚度导数、线性项、ε = δ²κ），说明两者不能互相替代，并以两者同时准确为设计判据。
