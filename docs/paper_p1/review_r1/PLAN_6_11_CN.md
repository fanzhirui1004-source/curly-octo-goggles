## 1. 讨论中发现、需要作者知晓的三点

1. **挪端点消除不了小碎片。** 斜率为 2/3 的直线穿过网格时必然会削掉或留下某些胞的一个小角。两个端点各在 ±0.5 胞内扫描，最小碎片始终约 8%。
   - 因此端点保持原定位置：底边右端 (8, 0) 到顶边 x = 2。保留 24 个胞：16 个完整，8 个切胞，保留体积为 0.08 / 0.33 / 0.67 / 0.92 各两个。
   - 8% 的碎片在训练与验证覆盖范围内：H1 的保留体积就是 0.086，验证集里保留 0.078–0.109 的胞 NICE 误差 ≤ 0.05%。
   - 若生成几何体时连通性检查不通过，再按 §6.9 的做法去掉该碎片胞，并在文中说明。
2. **内部存储时把板子转 90°。** 按原方向，切面法向角约 56°，超出训练的规范范围 [0°, 45°]。它是 34° 的镜像，物理等价，但网络对镜像不严格等变（E11：换视角误差高 4–12%）。所以内部把长边放在 y 方向，法向落在 34°；出图时转回来。
3. **边界条件（建议，待作者确认；在第 2 步实现前可改）。** 若左端固支，顶边只剩 x ∈ [0, 2] 一段且紧挨固支端，加载意义不大。建议改为**底边（8 胞长边）固支，顶面（剩下的约 2 个胞宽）加载**，这是一块带斜切自由边的梯形"墙"：
   - B1 面内：顶面水平方向（沿长边）的一致面载，墙体在面内受弯；
   - B2 z 向：顶面 z 向一致面载，单层板出平面受弯。

   这两种载荷都是现有格架代码"整面固支、整面加载"能直接表达的，不需要扩展加载代码。

## 2. 优化问题（所有算例共用）

- **变量**：格架顶点上的厚度参数 τ_g。相邻胞共享角点，τ_m = τ_m(τ_g) 是复制映射。
- **目标**：单载荷工况的柔度 Ĉ = fᵀÛ。载荷冻结在初始设计上（I-50）。
- **约束**：
  - 总体积 V(τ) ≤ V*。V 用单元零阶矩直接求和，对离散模型是精确的；dV/dτ 用矩导数。
  - 边界 0.18 ≤ τ ≤ 0.69（训练范围为 [0.1752, 0.6993]，留余量）。
  - 每胞角点跨度 ≤ 0.45，写成角点两两差值的线性约束。
  - 每胞厚度梯度范数（在 8 个角点处取三条棱的差值）≤ 0.45（训练上限 0.47）。
- **起点**：均匀 τ0 = 0.40。V* 默认取 0.8·V(τ0)，可调。
- **MMA 设置**：
  - 渐近线初值 0.5×变量范围，按标准规则收缩 0.7、放大 1.2；
  - 每步移动限制为变量范围的 5%；
  - 停止条件：max|Δτ| < 10⁻³，或目标相对变化连续 3 步 < 10⁻⁴；上限 60 步。
  - 不以梯度或 KKT 残差作停止判据（代理目标有小台阶，见 E3、E13）。
- **每步记录**：Ĉ、V、约束值；s̃ 聚合梯度；各胞离散开关（活跃单元数、鬼面数、保留集、二值节点特征、粗因子平移）；重算残差 ‖f − K̂Ū‖/‖f‖ 与 Ūᵀρ；分阶段计时（几何生成、前处理、求解、灵敏度、MMA）；GPU 与主机内存峰值。
- **精确核对点**：起点、约第 1/2 处、最终设计。报告：
  - 真实柔度，以及代理误差（I-20）；
  - 梯度误差、余弦、逐变量分位数、符号一致率（I-08、M1）；
  - 用精确梯度算的 KKT 残差（M3）。

## 4. 要写的代码（全部为新脚本或默认关闭的开关，不改已有脚本的默认行为）

1. `mma.py`：标准 MMA（子问题用对偶法求解），带解析测试题的单元测试。
2. `opt_design.py`：优化主循环。
   - 由顶点 τ 场生成各胞包与几何体：沿用 gen_hlat / r1_sweep 的包格式和 fast_prep4 几何体生成，只重建变了的胞，CPU 并行。
   - NICE 格架求解：lat_multi 与 bnn:kpp:q1r 预条件，上一步解作热启动。
   - s̃ 与顶点聚合：r1x3_common。
   - 体积及其梯度、约束、MMA 更新、日志、断点续跑。
3. `plate_gen.py`：切板布局，内部转 90°；切线参数、碎片策略、初始 τ 场。
4. `opt_exact.py`：精确凝聚一方的优化，供算例 A 使用，与 NICE 共用 MMA 和约束。精确灵敏度沿用参考解流程；GPU 稠密精确凝聚和 CPU 路线 (b) 取较快者，先实测。
5. 均匀化（`homog_cell.py`、`homog_macro.py`）：
   - 在我们的 CutFEM 离散上对均匀厚度胞做周期均匀化（6 个单位应变工况）；在 [0.18, 0.69] 取 10–15 个厚度值，样条插值得到 C^H(τ) 及其导数；
   - 宏观有限元：每胞若干个 Q1 单元，厚度按角点三线性插值后取 C^H；切胞按切面裁剪积分；
   - 伴随灵敏度，接同一个 MMA。
6. 规模展示：流式存储状态单精度化（环境变量开关，默认关闭）。不使用 fp16、bf16、TF32；先在 8 胞上核对精度不变。

## 6. 风险

- **几何体生成失败**（连通性检查）：碎片胞按 §6.9 的规则去掉，并记录下来。
- **优化器被代理"钻空子"**，跑向代理偏硬的设计：通过每步日志与精确核对点发现；若发生，在文中如实报告，并在训练范围约束上收紧。
- **切胞碎片在优化中形状变化较大**：它们受跨度和梯度约束。精确核对时单独报告切胞误差。
- **精确对照一方太慢**：先实测。若每步超过 30 分钟，把算例 A 的步数上限降到 30。
- **E13 的台阶高度若远大于 β 上界**：停止条件放宽到台阶尺度，文中说明。
