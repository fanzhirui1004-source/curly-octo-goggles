# R6 — Fact-check of internal consistency (MANUSCRIPT_EN.md, APPENDICES_EN.md, SUPPLEMENTARY_EN.md, FIGURES.md)

Scope: numerical claims in the Abstract and Sections 1–8, the consistency between Abstract, contributions, Discussion and Conclusions, cross-references, predictor/cell labels, and references. Section 6.11 and the "[Placeholder …]" sentences were skipped. No manuscript or evidence file was modified. Throw-away extraction scripts are in the session scratchpad (`r6/`).

Method: every main-text number was traced to a main-text table, a supplementary table or an evidence file. Where an evidence file exists, the number was recomputed from the unrounded record (`newval2_*.json`, `valmeta.json`, `gate_*.json`, `p1_checks*.json`, `ref_valid*.json`, `lam_check_val80.json`, `lat_hetero*_A3.json`, `lat_direct_*.json`, `learned_*.json`, `d5_off.json`, `bench_A3_cells.jsonl`, `bench_cpu*.json`, `time_setup.json`, `meta_p1.json`, `p1_field_M1_small.npz`). `latex/gen_supp_tables.py` was run in print mode. Its R1, ST01, ST01b, ST01c, ST07a, ST07b, ST12 and ST13 blocks match SUPPLEMENTARY_EN.md exactly.

Severity: **Error**: the stated value contradicts its source. **Inconsistency**: the same quantity is stated differently in two places, or a rounding or unit choice changes the stated value. **Unsupported**: no source was found, or the source does not cover the claim. **Style**: wording, precision or labelling that is misleading but not numerically wrong.

- Contribution (iv) "below one percent in all configurations examined" is consistent with ST13 (A3 ≤ 0.669%, B+W ≤ 0.945%).
