### 3.2. Network for the interior displacements

The network approximates the interior part of the exact recovery, the map \(q\mapsto E_Iq=-A^{-1}K_{IP}q\); this approximation yields a displacement field and, through its strain energy, the condensed stiffness on all retained DOFs (Section 3.1). Since a cell has 2,679 to 45,900 retained DOFs and this set changes with the cut, two direct approaches are unsuitable. Forming the recovery matrix for every geometry requires one interior solve per retained DOF, and a network with one output per retained DOF would need an output dimension that changes with the cut.

The relations of Sections 3.1 and 4 rest on three properties, which the architecture enforces exactly by construction: (i) at fixed geometry the recovery is linear in \(q\), since all nonlinearity is confined to a geometry branch and every operation on the displacement features is linear; (ii) the recovery reproduces the retained displacements and the rigid-body motions, since the rigid-body motion is separated before the network and reconstructed after it, and the retained displacements are overwritten at the output (Eq. (9)); (iii) the transpose of the recovery, which the nodal forces of Eq. (5) require, is obtained by transposing the linear displacement path operation by operation (Appendix G.1). Section 5.2 verifies the three properties numerically.

The remaining design choices determine how well the network approximates the map, and they were not tested individually by ablation. For each active element and each element face on which the ghost penalty acts, the network uses a fixed set of nodes, called a stencil. The weights of the network act on the local node positions of the stencils, on the feature channels and on the grid levels, and the coefficients of each stencil are computed from the geometry, so one network serves the sets of retained DOFs of all geometries within the range covered by training. Because the material boundaries intersect the background elements, the element moments, the integrals of local monomials over the material part of each background element (Appendix A.1), enter as geometry input. The map from the retained displacements to the interior displacements couples distant parts of the cell, and this long-range coupling is carried by a U-shaped grid hierarchy, which passes the features to successively coarser grids and back. Additional local interactions act on the stencils that contain weakly connected nodes, which are coupled to the rest of the cell by few and small stiffness entries.

The network therefore has two branches (Figure 3): a nonlinear geometry branch computes, once per geometry, the coefficients of a linear operator, and the displacement branch is this linear operator.

The rigid-body motion is separated before the network is applied. With the columns of \(R\) taken as three translations and three rotations about a common centre, the matrix \(C_R=(R_P^TR_P)^{-1}R_P^T\) extracts the rigid-body coefficients and the projector \(\Pi_P=I_p-R_PC_R\) removes the rigid-body part, which splits the input into the rigid-body coefficients \(C_Rq\) and the retained deformation \(q_d=\Pi_Pq\). The network acts only on \(q_d\), so the reconstruction of the rigid-body motion does not depend on how well the network is trained.

In the geometry branch, the element moments describe the material distribution within each background element, and the node features indicate whether a node carries retained DOFs, whether it belongs to the cut-plane elements and whether it is weakly connected, and also contain the local stiffness magnitude and the node position. A node is weakly connected when the norm of its diagonal stiffness block is below 1% of the median over the active nodes (Appendix G). Encoders map these inputs to element and node feature vectors, which exchange information in two rounds, and coefficient heads, small output networks, then compute the geometry-dependent coefficients: the weights of the fixed element–node and ghost-face–node connections, of the transfers between the grids of the hierarchy and of the coarse-grid convolutions. For a given geometry, these coefficients do not depend on the retained displacements.

The displacement branch lifts the three components of \(q_d\) to 32 feature channels on the retained nodes, the nodes that carry retained DOFs, and sets the features of the interior nodes to zero, which defines the initial features \(X^0(q)\). Local interactions propagate these values through the neighbourhoods of the elements and of the ghost-penalty faces. Each interaction gathers the features at the 27 local node positions of a stencil with four separate sets of geometry-dependent weights, called heads, mixes the channels within each head and scatters the result back to the nodes of the stencil. With \(\mathsf M_I\) and \(\mathsf M_P\) the masks of the interior and retained nodes, acting on nodal rows, one interaction updates the features by

\[
X^{\ell+1}=\mathsf M_I\left[X^\ell+
 \sum_h\mathcal S_{\ell h}(\eta)
   \big(\mathcal G_{\ell h}(\eta)X^\ell W_{\ell h}\big)\right]
 +\mathsf M_PX^0(q).
\tag{8}
\]

Here \(\mathcal G_{\ell h}\) and \(\mathcal S_{\ell h}\) are the gather and scatter maps with geometry-dependent weights, \(W_{\ell h}\) mixes the channels, and the last term restores the retained features. The U-shaped grid hierarchy, which provides the long-range coupling, passes through grids with 65, 33, 17 and 9 positions per axis, the finest of which is the \(Q_2\) node grid of the cell. Pairs of local interactions before and after the hierarchy, and further pairs on the stencils that contain weakly connected nodes, complete the branch, and a linear map then converts the features to nodal displacements (Figure 3b,c). Because the weights do not act on individual DOFs, the same network of about \(6\times10^5\) parameters serves every set of retained DOFs (Supplementary Table ST15). For a given channel width and stencil size, the work of one network application is proportional to the number of element and ghost-face stencils and to the size of the fixed grids, independent of how many of the nodes carry retained DOFs; one application processes a batch of retained displacement vectors at once. Appendix G gives the complete order of operations and the definitions of the coefficients.

Every operation on the displacement features is linear, and the nonlinear encoders act only on the geometry, so the raw map \(\mathcal N_\theta(\eta)\), with network parameters \(\theta\), obeys superposition at fixed \(\eta\). Adding back the rigid-body field and restoring the prescribed retained displacements gives the network recovery operator

\[
\widehat E q=J_P^Tq+
J_I^TJ_I\left[RC_Rq+\mathcal N_\theta(\eta)\Pi_Pq\right].
\tag{9}
\]

It follows that \(J_P\widehat E=I_p\), from the final overwrite of the retained displacements, and \(\widehat ER_P=R\), from the separation of the rigid-body motion; both relations hold by construction. The transpose \(\mathcal N_\theta(\eta)^T\) required by Eq. (5) is the composition of the transposed operations in reverse order (Eq. (E.1)), so that, in exact arithmetic, the returned nodal forces are the derivative of the strain energy \(\widehat{\mathcal U}\).

The data flow of the displacement branch resembles that of an iterative solver for the interior problem, in which the retained displacements are prescribed (Dirichlet) boundary values. Each local interaction of Eq. (8) updates the interior features from their stencil neighbours with geometry-dependent coefficients and, at the same time, resets the retained features to their lifted prescribed values, and the grid hierarchy carries information between distant parts of the cell, as the coarse levels do in multigrid. The resemblance is limited to the data flow, however: the branch never applies the stiffness matrix and does not compute residuals, the equilibrium solution of the interior problem is not a fixed point of its layers, and the branch is a fixed sequence of learned linear maps. The two-grid correction of Sections 3.3 and 3.4, in contrast, acts on the residual of the same interior problem with prescribed coefficients. Because the network is trained with this correction applied (Section 3.5), it provides the part of the interior displacement field that a fixed number of correction steps does not recover.
